学习Flutter4：导航与路由

路由（Route）和导航（Navigation）是 Flutter 应用中页面跳转的核心机制。Flutter 提供了一个完整的系统，用于在屏幕之间导航和处理深层链接。

一、核心概念

概念 说明 类比
Route 一个页面或屏幕的抽象，通常是一个 Widget 网页的 URL 对应的页面
Navigator 管理 Route 堆栈的组件 浏览器的历史记录栈
Context 当前 Widget 在树中的位置 导航的起点坐标

核心原理：Navigator 使用**堆栈（Stack）**结构管理页面：

  • push：新页面入栈（跳转）
  • pop：当前页面出栈（返回）

Navigator常用方法

方法 说明 示例
push 跳转到新页面 Navigator.push(context, route)
pushNamed 通过命名路由跳转 Navigator.pushNamed(context, '/about')
pushReplacement 替换当前页面 Navigator.pushReplacement(context, route)
pushNamedAndRemoveUntil 跳转并移除之前的页面 见下方示例
pop 返回上一页 Navigator.pop(context)
popUntil 一直返回到指定路由 Navigator.popUntil(context, (route) => route.isFirst)
maybePop 有页面才返回 Navigator.maybePop(context)
canPop 检查是否能返回 if (Navigator.canPop(context)) Navigator.pop(context)

  1. 导航器（Navigator）
