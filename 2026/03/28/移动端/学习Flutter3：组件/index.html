学习Flutter3：组件

常用组件

一、布局组件

组件 作用 特点
Row 水平方向排列子组件 主轴为水平方向，可设置对齐方式（start/center/end/spaceBetween等）
Column 垂直方向排列子组件 主轴为垂直方向，与 Row 用法对称
Stack 层叠布局（类似绝对定位） 子组件可以重叠放置，通过 Positioned 精确定位
Expanded 填充 Row/Column 的剩余空间 必须用在 Row/Column 中，支持 flex 比例分配
Flexible Expanded 的灵活版 可设置 fit 为 loose（不强制填满）或 tight（强制填满）
Wrap 自动换行布局 超出空间自动换行，支持 spacing 和 runSpacing
Flow 高级自定义换行布局 性能好但使用复杂，需要自定义 delegate
ListView 可滚动列表（垂直或水平） 适合子组件数量不确定或大量数据时使用
GridView 网格布局 支持设置交叉轴个数（crossAxisCount）或最大宽度
CustomScrollView 自定义滚动效果 可组合 Sliver 实现复杂滚动（如吸顶效果）

二、容器组件

组件 作用 特点
Container 多功能容器 可同时设置宽高、内边距、外边距、装饰（圆角/阴影/渐变）、背景色、旋转等
Padding 设置内边距 比 Container 更轻量，专门用于填充
Center 居中布局 让子组件在其内部水平和垂直居中
SizedBox 固定尺寸盒子 可用于设置具体宽高，或创建空白间隔（常用来代替 Container 做间距）
ConstrainedBox 添加约束 设置 minWidth/maxWidth/minHeight/maxHeight
LimitedBox 限制最大宽高 当父组件无约束时生效，如 ListView 内部
AspectRatio 固定宽高比 子组件宽高比固定（如 16:9）
FittedBox 缩放子组件适应父级 自动缩放子组件以完全填充父容器
FractionallySizedBox 按比例设置尺寸 宽度为父级的 70% 可以写 widthFactor: 0.7
DecoratedBox 添加装饰 背景色、边框、阴影、渐变等（Container 内部使用了它）

三、文本与图片组件

组件 作用 特点
Text 显示文本 支持 style（TextStyle 设置字体/颜色/大小）、textAlign、maxLines、overflow
RichText 富文本 使用 TextSpan 组合不同样式的文本片段
TextField 文本输入框 支持 decoration（边框/图标/提示文字）、controller 控制、onChanged 监听
Image 显示图片 支持多种来源：AssetImage（本地）、NetworkImage（网络）、FileImage（文件）
Icon 显示图标 配合 Icons 类使用，如 Icon(Icons.favorite)
CircleAvatar 圆形头像 支持背景色、背景图片、文字（用于显示用户头像）
Chip 标签组件 用于显示标签、筛选条件，支持删除、头像等

四、输入与交互组件

组件 作用 特点
ElevatedButton 凸起按钮 Material Design 3 风格，有阴影和背景色
TextButton 文本按钮 无边框，适用于不重要操作
OutlinedButton 边框按钮 带边框，无阴影
IconButton 图标按钮 点击区域为圆形，常用于 AppBar
FloatingActionButton 悬浮按钮 常用在 Scaffold 右下角，圆形且带阴影
Checkbox 复选框 用于多选，通过 value 和 onChanged 控制
Radio 单选框 用于单选组，需要配合 groupValue 使用
Switch 开关按钮 用于切换布尔状态
Slider 滑动条 用于范围选择（如音量、亮度）
GestureDetector 手势检测 可检测点击、双击、长按、拖动等多种手势
InkWell 带水波纹的手势检测 相比 GestureDetector 多出 Material 水波纹效果
Draggable 可拖拽组件 支持拖拽时显示反馈图像
DragTarget 拖拽目标组件 接收 Draggable 拖拽的数据

五、异步与状态管理组件

组件 作用 特点
FutureBuilder 处理 Future 异步数据 根据异步状态（等待/成功/失败）自动切换界面
StreamBuilder 处理 Stream 数据流 监听 Stream 数据变化，自动重建
ValueListenableBuilder 监听 ValueNotifier 轻量级状态管理，适合局部简单状态
AnimatedBuilder 构建动画 将动画逻辑与 UI 分离，避免不必要的重建
OrientationBuilder 响应屏幕旋转 根据横竖屏状态返回不同布局
LayoutBuilder 获取父组件约束 根据父级提供的最大/最小宽高动态布局

六、导航与路由组件

组件 作用 特点
Navigator 路由管理器 通过 push/pop 管理页面栈，支持命名路由
MaterialPageRoute Material 风格页面切换 提供平台特定转场动画（iOS 左右滑动，Android 上下滑动）
CupertinoPageRoute iOS 风格页面切换 iOS 风格的左右滑动动画
PageView 页面滑动切换 支持左右滑动切换页面，可配置是否循环
TabBar + TabBarView 标签页布局 顶部标签栏 + 对应页面内容的滑动切换
BottomNavigationBar 底部导航栏 常见于 App 底部 Tab 切换，最多支持 5 项

七、辅助与装饰组件

组件 作用 特点
SafeArea 避开系统状态栏、刘海区域 确保内容不被系统 UI 遮挡
MediaQuery 获取屏幕信息 可获取屏幕尺寸、文字缩放比例、暗黑模式状态等
Scaffold 页面基本结构 提供 AppBar、body、FloatingActionButton、Drawer、SnackBar 等
AppBar 顶部应用栏 可设置标题、返回按钮、操作按钮（actions）
Drawer 侧边栏菜单 配合 Scaffold 的 drawer 属性，从左侧滑出
SingleChildScrollView 单个子组件滚动 子组件内容超出屏幕时可滚动
RefreshIndicator 下拉刷新 配合 ListView 使用，提供 Material 风格的下拉刷新效果
WillPopScope 拦截返回操作 在用户按返回键时执行自定义逻辑（如退出提示）
Hero 共享元素动画 两个页面间相同 tag 的组件切换时自动产生平滑过渡动画
Tooltip 提示工具 长按组件时显示提示文字
Opacity 透明度控制 改变子组件的透明度（0.0-1.0）

常用组合模式速查

场景 推荐组件组合
登录表单 Column + TextField + Padding + ElevatedButton
商品列表页 Scaffold + AppBar + ListView.builder
图片轮播 PageView + Stack + Positioned（指示点）
底部导航 Scaffold + BottomNavigationBar + IndexedStack
下拉刷新 + 上拉加载 RefreshIndicator + ListView + 配合 ScrollController
卡片式布局 Container（带 decoration 圆角阴影）+ Column + Row
响应式网格 LayoutBuilder + GridView（根据屏幕宽度动态改变 crossAxisCount）

选择组件的简单原则

  1. 布局优先考虑 Row/Column + Expanded，不要一开始就嵌套多层
  2. 需要装饰（圆角、阴影）用 Container，否则用更轻量的 SizedBox/Padding
  3. 列表永远用 ListView.builder 而不是手动添加多个组件
  4. 手势检测优先用 InkWell（有水波纹反馈），否则用 GestureDetector
  5. 文本输入记得用 TextEditingController 并 dispose 释放资源
  6. 异步数据用 FutureBuilder 可以少写很多状态判断代码

点击效果分类

1. 水波纹效果（Material 风格）

这些组件默认带有 InkWell 水波纹，是 Material Design 的标准反馈：

组件 默认效果 备注
InkWell ✅ 水波纹 直接使用，可包裹任何组件
InkResponse ✅ 水波纹 InkWell 的底层，更灵活
ListTile ✅ 水波纹 设置 onTap 后出现
ElevatedButton ✅ 水波纹 Material 3 按钮
TextButton ✅ 水波纹 Material 3 按钮
OutlinedButton ✅ 水波纹 Material 3 按钮
IconButton ✅ 圆形水波纹 固定圆形效果
Card ⚠️ 需设置 默认无效果，需包裹 InkWell
Chip ✅ 水波纹 设置 onTap 后出现
GestureDetector ❌ 无效果 需手动实现

2. 高亮背景效果（非水波纹）

这些组件点击时会有背景色变化，但没有水波纹：

组件 效果类型 备注
CupertinoButton 半透明叠加 iOS 风格，无波纹
CupertinoListTile 灰色高亮 iOS 风格列表项
Radio 变色 + 动画 单选按钮
Checkbox 变色 + 动画 复选框
Switch 滑块动画 开关
Slider 滑块动画 滑动条

3. 自定义点击效果组件

这些组件需要通过配置才能产生效果：

组件 如何添加效果
Container 包裹 InkWell
Card 包裹 InkWell
Image 包裹 InkWell 或 GestureDetector
Text 包裹 GestureDetector 或 InkWell

如何禁用点击效果？

方法1：使用 GestureDetector（默认无效果）

方法2：设置透明高亮（不推荐）

方法3：使用 AbsorbPointer（完全禁用交互）
