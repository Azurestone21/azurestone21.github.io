运行项目

1. flutter run

  • flutter run 会按照以下优先级自动选择一个可用设备：
    1. 已连接的真机（按连接顺序，通常是第一个连接的）
    2. 已启动的模拟器/虚拟机（如果真机不存在）
    3. 如果同时有多个设备可用，Flutter会提示用户选择一个设备。

2. flutter run -d <device>

指定目标设备

编译模式

模式 主要用途 JIT/AOT 热重载 调试信息 性能
–debug 开发调试 JIT（即时编译） ✅ 支持 完整 最慢
–profile 性能分析 AOT（预编译） ❌ 不支持 部分 接近release
–release 正式发布 AOT（预编译） ❌ 不支持 无 最快

热重载

启动项目后，修改代码后，在终端直接输入 r 即可热重载。
