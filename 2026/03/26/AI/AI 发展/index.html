AI 发展

AI 发展

第一阶段：大模型唤醒（2022–2023）——“会说”的诞生

关键词：ChatGPT、GPT-4、百模大战

2022 年 11 月 30 日，OpenAI 发布 ChatGPT，基于 GPT-3.5 并引入 RLHF 人类对齐，两个月内用户破亿，成为历史上增长最快的消费级应用。它的前身可以追溯到 2022 年 2 月的 InstructGPT，那是“对齐”思路的首次系统验证。

2023 年 3 月 14–15 日，OpenAI 发布 GPT-4，引入多模态和复杂推理能力，被广泛视为“地表最强模型”。大模型从“能聊天”进化为“能看图、能推理”。

中国的“百模大战”几乎与 GPT-4 同步打响。2023 年 3 月，百度率先发布 文心一言；4 月，阿里上线 通义千问；5 月，科大讯飞发布 星火认知大模型；7 月，华为云盘古 3.0 和 京东云言犀相继问世。至少 130 家公司投入大模型研发。

这一阶段的 AI 本质上是对话式文本生成器：它能写、能译、能答，但不能主动做事。模型无状态，知识截止于训练数据。开发者的全部武器，是Prompt Engineering——角色设定、Few-shot、思维链。Prompt 管的是“这一次怎么说”，它的天花板很快就暴露了。

第二阶段：从“说”到“做”的转折（2023–2024）——“手”和“脑”的第一次尝试

关键词：Function Calling、AutoGPT/BabyAGI、o1

2023 年 3 月，AutoGPT 发布（GPT-4 上线后两周内），BabyAGI 紧随其后。它们试图让模型自主规划、调用工具、循环执行多步任务，GitHub 星标数周内突破 10 万。但可靠性很低：容易陷入循环、偏离目标、无法从错误中恢复。这是“自主 Agent”的第一次公开尝试，也是第一次公开失败。

2023 年 6 月 13 日，OpenAI 发布 Function Calling，让模型以结构化 JSON 输出工具调用意图，工具从 Prompt 里的文本约定，变成 API 的一等公民。这是 Agent 从“文本解析”走向“结构化调用”的分水岭。

2024 年 9 月，OpenAI 发布 o1 系列推理模型，首次将“慢思考”内化到模型本身，在数学、科学、代码任务上大幅超越 GPT-4o（例如美国数学奥林匹克预选赛准确率从 13% 跃升至 83%）。推理能力开始从外部框架（Plan-and-Execute、Reflexion）迁移到模型内部。

2024 年 11 月，Anthropic 开源 MCP（Model Context Protocol），把“工具怎么被发现、怎么被调用”标准化。这是连接层的奠基，但它的上下文开销问题很快暴露，为下一阶段的 Context Engineering 埋下伏笔。

这一阶段的核心矛盾是：模型学会了“调用工具”，但还不知道“在什么信息环境下调用才可靠”。

第三阶段：Agent 元年与成本革命（2025）——“会做”开始真正跑通

关键词：DeepSeek R1、编程 Agent、Context Engineering、MCP 与 Skill 的生态化

2025 年 1 月 20 日，深度求索（DeepSeek） 发布 DeepSeek R1，6710 亿参数的开放权重推理模型，性能对标 OpenAI o1，训练成本仅约 560 万美元，远低于美国巨头的数亿乃至数十亿美元投入。发布后英伟达市值大幅蒸发，市场第一次认真对待“顶尖能力不必依赖天价算力”这个命题。R1 的开放权重特性，也让研究人员第一次能“打开引擎盖”研究推理模型的内部机制。

编程 Agent 成为这一年第一个真正跑通的产品形态。2025 年 2 月 24 日，Anthropic 以研究预览形式发布 Claude Code，5 月全面上线，三个月内使用量增长超 10 倍，年化收入突破 5 亿美元，随后迅速攀升至 25 亿美元量级。2025 年 4 月 17 日，OpenAI 发布开源终端编程智能体 Codex CLI，与 o3/o4-mini 同步推出。AI 从“补全代码”进化为“分析任务、修改多文件、运行测试、提交 PR”的执行者。

2025 年，Context Engineering 成为行业共识。Karpathy 等人的推动让行业意识到：模型能力不再是唯一瓶颈，让模型在每一步看到恰好够用的信息才是工程关键。METR 的数据显示，AI 能独立完成的任务时长大约每 7 个月翻一番。

这一年也是连接层和流程层生态化的关键年。MCP 在 11 月满一周年时，公共服务器已超过 10,000 个，被 ChatGPT、Cursor、Gemini、Microsoft Copilot、VS Code 等主流产品采纳，SDK 月下载量超过 9700 万。2025 年 10 月，Anthropic 推出 Agent Skills，12 月作为开放标准发布，到 2026 年已有超过 70 个智能体平台集成，累计发布 100 万个 Skill、安装近 2.8 亿次。Skill 回答的是“这一类事按什么流程做”，与 MCP 的“能不能连”形成互补。

第四阶段：Harness 时代（2026）——让“会做”变得可靠、安全、可治理

关键词：Harness Engineering、Agent = Model + Harness、编程 Agent 产品市场契合

2026 年 2 月 5 日，HashiCorp 联合创始人 Mitchell Hashimoto 在博客中首次命名 Harness Engineering；2 月 11 日，OpenAI 发布《Harness engineering: leveraging Codex in an agent-first world》，将这一概念推向行业中心。

Agent = Model + Harness 成为共识。模型提供推理，Harness 提供工具执行、上下文管理、记忆、安全边界、编排调度。一个被反复引用的工程事实是：同一个模型，只调整 Harness 层的系统提示、工具描述和中间件，评测成绩就能从明显落后追到接近榜首，而成本只有对方的十分之一左右。

编程 Agent 在这一年达到产品市场契合。Claude Code 的年化收入从 2025 年的 5 亿美元级别，在 2026 年初攀升至 25 亿美元量级，用户平均每周使用 20 小时。有团队开始实践“代码不由人类编写，也不由人类审查”的工作流，人类负责定义目标和验收标准，AI 负责生成和验证。与此同时，Agent 的可靠性、安全边界、长任务稳定性仍然是核心挑战。提示注入无法在模型层可靠修复，缓解措施必须放在 Harness 中——通过控制 Agent 能访问什么、被允许执行什么来防御。

能力迁移总表：瓶颈在往哪里走

年份 关键节点（公司 / 模型 / 概念） 核心瓶颈 工程焦点
2022.11 OpenAI ChatGPT 模型能不能对话 Prompt Engineering
2023.03 OpenAI GPT-4；百度文心一言；AutoGPT/BabyAGI 模型能不能理解复杂指令、能不能自主循环 Prompt Engineering、早期 Agent 实验
2023.06 OpenAI Function Calling 模型能不能结构化地“说”要调工具 Function Calling、工具标准化
2024.09 OpenAI o1 模型能不能“慢思考” 推理模型、Agent 循环
2024.11 Anthropic MCP 工具能不能标准化连接 连接层标准化
2025.01 深度求索 DeepSeek R1 顶尖能力能不能低成本获得 成本革命、开放权重
2025 上半年 Anthropic Claude Code、OpenAI Codex CLI AI 能不能真正干完编程活 编程 Agent 产品化
2025.10–12 Anthropic Agent Skills 这一类事怎么按标准流程做 流程复用、渐进式加载
2026.02 Mitchell Hashimoto / OpenAI Harness Engineering 整个系统能不能安全、可控、持续地干活 Harness 治理、执行边界、可观测性

一句话总结这几年：模型从“会说”走向“会做”。Prompt 管这一次怎么说，Function Calling 管怎么“说”要调工具，MCP 管工具怎么接，Skill 管这一类事怎么做，Context Engineering 管每一步看什么，Harness 管整个系统怎么安全地一直做下去。 每一层都在补上一层的缺口，而不是取代上一层。
