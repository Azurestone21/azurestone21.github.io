一、概述

XSS（Cross-Site Scripting，跨站脚本攻击），缩写原本为CSS，但这与HTML中的层叠样式表（Cascading Style Sheets）缩写重名了，为了区分就将跨站脚本改为了XSS。

其本质是：攻击者把恶意脚本注入到网页中，让浏览器在目标站点的源下，把它当作正常代码执行。

浏览器无法区分“开发者写的 JS”和“攻击者注入的 JS”，只要它们出现在同一个页面里，就会在同一个源下运行。因此 XSS 相当于绕过了同源策略的信任边界，攻击者代码“变成”了目标站点的一部分。

核心公式：

用户输入 → 未编码输出 → 浏览器解析为代码 → 在目标域下执行

二、XSS 发生的四个条件

  1. 有用户可控输入：URL 参数、表单、评论、昵称、富文本等。
  2. 输入未正确处理：没有做输出编码、过滤或消毒。
  3. 输出到了可执行上下文：HTML 文本、属性、<script>、事件、URL、CSS、JS 字符串等。
  4. 受害者访问或触发：浏览器解析页面时执行了恶意脚本。

三、XSS 的三种类型

1. 反射型 XSS

恶意脚本放在请求里，服务器把它“反射”回响应 HTML。需要诱导用户点击恶意链接，不持久化。

四、危害

  • 窃取 Cookie / Token / Session
  • 冒充用户发请求
  • 篡改页面、弹窗钓鱼
  • 键盘记录、表单劫持
  • 传播蠕虫
  • 配合 CSRF 扩大攻击
