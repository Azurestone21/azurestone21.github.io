4. 检查的是属性存在性，不是值

in 只看属性是否存在，不关心值是什么。

数组索引本质是属性名，所以 1 in arr 等价于判断 "1" 这个属性是否存在。

7. 对 Map / Set 不适用

in 检查的是对象属性，不是 Map / Set 内部存储的键值。

10. 推荐方法速查

场景 推荐方法
对象自身属性 Object.hasOwn(obj, key)
对象包括原型链属性 key in obj
数组是否包含值 arr.includes(value)
数组索引是否存在 index in arr
Map 是否有键 map.has(key)
Set 是否有值 set.has(value)

11. 易错点总结

  • in 检查的是属性名，不是值。
  • 右操作数必须是对象，原始值会报错。
  • 会检查原型链，可能得到意料之外的 true。
  • 数组索引用 in 可以判断空槽，但不能判断元素值。
  • Map / Set 不要用 in，要用 has。
  • 只想检查自身属性时，用 Object.hasOwn。
