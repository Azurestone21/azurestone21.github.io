【JS】可迭代协议

可迭代协议（Iterable Protocol） 是 JavaScript 定义的一套统一接口，用来规定“一个对象如何被遍历”。实现了这个接口的对象，就可以被 for...of、展开运算符 ...、解构、Array.from 等语法消费。

它包含两个层面：

  1. 可迭代协议：对象必须有 [Symbol.iterator]() 方法。
  2. 迭代器协议：[Symbol.iterator]() 返回的对象必须有 next() 方法。

1. 可迭代协议

一个对象只要拥有 Symbol.iterator 方法，它就是“可迭代对象”。

for...of 会先调用 iterable[Symbol.iterator]()，拿到迭代器，然后不断调用 next()。

6. 可迭代协议用在哪里？

很多语法和 API 都依赖它：

  • for...of
  • 展开运算符：[...iterable]
  • 解构：const [a, b] = iterable
  • Array.from(iterable)
  • new Map(iterable)
  • new Set(iterable)
  • Promise.all(iterable)
  • yield* 委托

7. 和 for...in 的区别

for...in 可迭代协议 /for...of
机制 枚举属性名 调用[Symbol.iterator]()
遍历内容 键名 迭代器返回的值
原型链 会包含可枚举原型属性 取决于迭代器实现
Symbol 键 不遍历 取决于迭代器
普通对象 可以直接用 默认不能用
Map 通常遍历不到内部数据 可以直接遍历键值对

所以：

  • for...in 是“枚举属性”的机制。
  • for...of 是“消费可迭代协议”的机制。

总结

可迭代协议就是：对象通过 [Symbol.iterator]() 告诉 JavaScript “我该怎么被遍历”。

  • 有 [Symbol.iterator]() → 可迭代对象。
  • 返回的对象有 next() → 迭代器。
  • next() 返回 { value, done } → 迭代器协议。
  • for...of、展开、解构等都会使用这套协议。

普通对象默认没有实现它，所以不能直接 for...of；但 Map、Array、Set 等内置对象都实现了。
