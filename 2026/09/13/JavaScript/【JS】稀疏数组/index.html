稀疏数组是什么？

稀疏数组（Sparse Array） 指的是数组的索引不连续，存在一个或多个“空槽”（hole），也就是某些索引位置没有对应的元素。

关键点：空槽 ≠ undefined。

虽然访问 sparse[1] 也返回 undefined，但 1 in sparse 是 false，说明这个索引根本没有被创建。

怎么产生稀疏数组？

a.length、b.length、c.length 都是 3、3、6，但实际存在的元素个数不等于 length。

空槽在不同遍历中的表现

操作 是否跳过空槽
for 循环 不跳过，访问返回undefined
for...in 跳过
for...of 不跳过，返回undefined
forEach / map / filter / some / every 跳过
Object.keys / Object.entries 跳过
JSON.stringify 空槽转成null

为什么建议避免稀疏数组？

  1. 行为不一致：不同遍历方法对空槽的处理不同，容易出 bug。
  2. 性能问题：JS 引擎可能会把稀疏数组转成“字典模式”，访问速度变慢。
  3. 序列化陷阱：JSON.stringify 会把空槽变成 null，丢失信息。
  4. 可读性差：[1, , 3] 很容易被看漏。

总结

  • 稀疏数组：索引不连续，存在空槽。
  • 空槽：索引不存在，访问返回 undefined，但 in 检测为 false。
  • 密集数组：每个索引从 0 到 length-1 都存在。
  • for...in 会跳过空槽，for...of 和普通 for 不跳过。
  • 日常开发中尽量创建密集数组，避免依赖稀疏数组的特殊行为。
