React + Jest 前端项目单元测试

单元测试：Jest

Jest 介绍

Jest 是一个JavaScript测试框架，专注于简单性。

适用于使用Babel、TypeScript、Node、React、Angular、Vue等的项目。

Jest 不支持 Vite。

入门

  • 安装
  • package.json：配置启动命令

使用 TypeScript

TypeScript 预处理器

  • ts-jest ：Jest 的 TypeScript 预处理器，负责在运行测试前把 .ts 文件转换掉。

配置 jest.config.js

除了ts-jest，也可以使用 Babel

类型定义

有两种方法可以为用 TypeScript 编写的测试文件输入 Jest 全局 API。

  1. @jest/globals：需要导入 API 使用。Jest 附带的类型定义，并且每次更新 Jest 时都会更新。
  2. @types/jest：无需导入 API。但 @types/jest 是 DefinitelyTyped 维护的第三方库，因此可能尚未涵盖最新的 Jest 功能或版本。尽可能匹配 Jest 和 @types/jest 的版本。

常用 Jest API 速查

1 组织测试 describe

it 和 test 完全等价，同一项目内保持统一即可。

2 常用匹配器

匹配器 用途
toBe 严格相等（===），适合数字、字符串、布尔值
toEqual 递归比较对象/数组内容
toHaveLength 数组或字符串长度
toContain 数组包含元素 / 字符串包含子串
toThrow 断言函数抛出异常
toBeNull / toBeUndefined / toBeTruthy 空值、真值判断
.not 任何匹配器前加 .not 取反

3 Mock 函数

4 模块 Mock

jest.mock 会被提升到文件顶部；工厂函数里不能引用外部变量（除非变量名以 mock 开头）。

5 异步测试

异步用例建议加 expect.assertions(n) 或 expect.hasAssertions()，防止断言未执行就被误判通过。

6 假定时器

假定时器是全局替换，afterEach 必须恢复，否则会影响同文件其他用例。涉及 Promise + 定时器混用时，用 jest.advanceTimersByTimeAsync(ms) 并 await，它会同时处理微任务。

测试重点

  1. 纯函数与工具逻辑：格式化、校验、计算、数据转换——性价比最高，优先覆盖。
  2. 自定义 Hooks：用 renderHook 单独测状态变化和副作用。
  3. 关键组件的用户交互：分支渲染、回调调用、加载/错误态——只测用户能感知的行为。
  4. 异步数据流：加载中 → 成功渲染、加载中 → 报错 → 错误态。推荐用 MSW 在网络层拦截请求。
  5. 不测：纯展示组件、样式布局、第三方库的简单封装、无意义的快照。
