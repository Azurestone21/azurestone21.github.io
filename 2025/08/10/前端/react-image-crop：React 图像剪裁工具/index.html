react-image-crop：React 图像剪裁工具

react-image-crop

介绍

react-image-crop 是一个无依赖的React图像裁剪工具。

特点

  • 响应式（可以用像素或百分比）
  • 可触控
  • 可以用任意比例进行剪裁（方形/圆形）
  • 没有依赖/小容量（<5KB gzip）
  • 最小/最大作物尺寸

缺点

  • 需要自己使用 Canvas 导出图片
  • 原生功能图片不支持缩放，可以自己使用 CSS 的 transform 缩放。

参数

参数 类型 描述 默认值
onChange（必填） (crop: PixelCrop, percentCrop: PercentCrop) => void 每次裁切变化都会触发的回调。传递当前的作物状态对象
crop Crop 裁剪的区域
aspect number 裁剪的宽高比，例如： 无论是方形还是风景。对于自由格式裁剪，省略/传递undefined。
minWidth number 最小裁剪宽度，像素数。
minHeight number 最小裁剪高度，像素数。
maxWidth number 最大裁剪宽度，像素数。
maxHeight number 最大裁剪高度，像素数。
keepSelection boolean 保持裁剪选择区域。如果true通过，那么用户点击选择区域外时，选择功能无法被禁用。 false
disabled boolean 如果属实，用户无法调整大小或绘制新的裁剪。容器中还添加了一个类 ，用于用户样式管理。ReactCrop–disabled
locked boolean 如果成立，用户无法创建或调整裁剪大小，但仍可拖动现有裁剪。容器中还添加了一个类 ，用于用户样式管理。ReactCrop–locked
className string 一串可以添加到主元素的类。ReactCrop
style React.CSSProperties 内联样式，将对象传递给图像包装元素。
onComplete (crop: PixelCrop, percentCrop: PercentCrop) => void 在调整尺寸、拖拽或推动后发生的回调。传递当前的作物状态对象。
onDragStart (e: PointerEvent) => void 当用户开始拖拽或调整裁剪框大小时，会发生回调。操作该组件之外的元素非常方便。
onDragEnd (e: PointerEvent) => void 当用户停止拖拽或调整裁剪框大小时，会发生回调。
renderSelectionAddon (crop: PixelCrop, percentCrop: PercentCrop) => void 在裁剪选择中渲染一个自定义元素。
ruleOfThirds boolean 在裁剪区域显示三分法则线。 false
circularCrop boolean 将裁剪区域显示为圆圈。如果你的图不是正方形，那么圆会变形成椭圆形。 false
