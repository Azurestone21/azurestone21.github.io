MCP 模型上下文协议

MCP 模型上下文协议

一、MCP 是什么

MCP（Model Context Protocol） 是一份开放协议，用于标准化 AI 应用与外部工具、数据源之间的连接方式。它的核心定位是解决“工具怎么被发现、怎么被调用、怎么跨应用复用”的问题，而不涉及“模型怎么决定调工具”——那是 Function Calling 的职责。

一句话记忆：MCP 管“工具从哪来、怎么接”，Function Calling 管“模型怎么表达要调它”。

MCP 的设计灵感来自 Language Server Protocol（LSP）——LSP 让编辑器无需为每种编程语言单独适配，MCP 让 AI 应用无需为每个工具单独写对接代码。

二、谁定义的，现在归谁管

MCP 由 Anthropic 于 2024 年 11 月开源。2025 年 12 月，Anthropic 将 MCP 捐赠给 Linux 基金会旗下的 Agentic AI Foundation（AAIF），该基金会由 Anthropic、Block 和 OpenAI 共同创立，Google、Microsoft、AWS、Cloudflare 等提供支持。治理模式不变，但协议归属已从单一厂商变为中立基金会。

三、架构：Host、Client、Server 三层

MCP 采用 Host–Client–Server 架构，职责严格分离：

Host（宿主应用）：面向用户的程序，如 Claude Desktop、Cursor、自研 Agent。它创建并管理多个 Client，控制连接权限和安全策略，持有完整对话历史。Server 看不到完整对话，这是 MCP 的安全边界。

Client（客户端）：Host 内部的连接器，每个 Client 与一个 Server 建立一对一连接。负责协议协商、消息路由，在 Server 之间维持隔离。

Server（服务端）：能力的提供方，通过 MCP 原语暴露功能。设计原则是“容易构建”和“可组合”——每个 Server 只做一件聚焦的事。

四、Server 暴露什么：三大原语

MCP Server 通过三种原语提供能力：

Resources（资源）：只读的上下文数据，如文档、数据库记录、文件内容。供模型或用户读取，用于减少幻觉、提供真实信息。

Prompts（提示词模板）：可复用的交互模板，引导模型在特定领域遵循一致的工作流。

Tools（工具）：可执行的函数，如发送邮件、查询订单、调用 API。这是与 Function Calling 直接对接的部分。

五、通信机制：JSON-RPC 2.0 + 无状态设计

MCP 底层使用 JSON-RPC 2.0 消息格式。协议是无状态的：每个请求自包含，携带自己的协议版本和客户端能力声明。

传输方式有两种标准实现：

  • stdio：客户端启动 Server 作为子进程，通过标准输入输出通信。适合本地工具。
  • Streamable HTTP：每条消息是一个 HTTP POST，响应可以是 JSON 或 SSE 流。适合远程服务。

连接建立时双方进行能力协商：Server 声明支持工具、资源还是提示词；Client 声明支持采样、elicitation 等。未声明的功能不可用，保证可扩展性和向后兼容。

六、安全原则

MCP 规范明确了几条底线：

  • 用户知情与同意：所有数据访问和操作，用户必须明确知情并同意。
  • 数据最小化：Server 只收到必要的上下文信息，完整对话历史留在 Host。
  • 工具即代码执行：Tools 本质上是任意代码执行路径，必须谨慎对待。工具描述中的注解应视为不可信，除非来自可信 Server。
  • 显式授权：Host 在调用任何工具前必须获得用户明确同意。

实现者应构建健壮的同意与授权流程，实施适当的访问控制，并遵循安全最佳实践。

七、和 Function Calling 的关系（核心区别）

这是最容易混淆的地方，必须分清：

Function Calling MCP
本质 模型能力（API 内置） 连接协议（标准化）
解决什么 模型怎么“说”要调什么 工具怎么“接”进来
谁生成调用 模型生成 tool_calls 不生成调用，只传递
执行在哪 应用侧 应用侧（可能经 MCP Client 转发）

完整链路：MCP Server 暴露工具定义 → Client 转换成模型能识别的 Function Calling Schema → 模型生成调用请求 → 应用执行（可能经 MCP Client 发给 Server）→ 结果回填模型继续推理。

所以 MCP 提供的是工具来源，不是直接喂给 Function Calling 的上游数据。用了 MCP，底层仍然是模型在生成调用意图。

八、生态现状（截至 2025 年底）

根据 Anthropic 官方数据：

  • 超过 10,000 个活跃的公开 MCP Server
  • ChatGPT、Cursor、Gemini、Microsoft Copilot、VS Code 等主流产品已采纳
  • AWS、Cloudflare、Google Cloud、Microsoft Azure 提供部署支持
  • Python 和 TypeScript SDK 月下载量合计 9700 万+

九、总结

MCP 是 AI 应用连接外部世界的“USB 接口标准”：它不决定模型要不要插设备，只保证插上去能识别、能通信、能复用。Function Calling 是模型说“我要用哪个设备”，MCP 是让这个设备真正能被找到和调用的基础设施。
