常用命令

Codex 的快捷操作主要分为斜杠命令 (/) 和键盘快捷键两类，分别用于控制 Codex 本身和操作界面。

常用键盘快捷键 (TUI)

这些快捷键主要用于在 Codex 的终端界面（TUI）中进行导航和编辑。

快捷键 (Mac/Win) 功能 说明
Ctrl + C 取消当前操作 / 退出 按一次取消，按两次强制退出
Ctrl + D 退出 Codex 当输入框为空时使用
Ctrl + L 清屏 清除终端屏幕，但保留当前对话历史
Ctrl + O 复制输出 复制 Codex 最近一条已完成输出的内容
Ctrl + G 打开编辑器 打开外部编辑器（由 VISUAL 或 EDITOR 环境变量指定），方便编写长指令
Tab 自动补全 自动补全斜杠命令 (/)
Ctrl + R 恢复会话 恢复之前的会话
Ctrl + P 打开命令面板 如果启用的话
↑ / ↓ 命令历史 在输入框中浏览之前输入的命令历史

核心斜杠命令 (/)

斜杠命令是 Codex 的“控制指令”，用于管理会话、切换模型等。在输入框直接输入以 / 开头的命令即可。

命令 功能 说明
/clear 清空对话 清空当前对话历史，但保留配置，相当于“重新开始”
/model 切换模型 在当前会话中切换 AI 模型，如 /model gpt-4o
/status 查看状态 显示当前会话的配置和状态信息，如模型、Token 用量等
/review 代码审查 触发一个专门的代码审查流程，分析你的更改
/diff 查看改动 以 Git 差异的形式列出当前所有的文件改动
/compact 压缩上下文 将当前对话压缩成摘要，以腾出 Token 空间
/help 显示帮助 显示所有可用的斜杠命令
/exit 退出会话 退出当前的交互式会话

💡 其他快捷操作

  • @ 前缀：在输入框中使用 @ 可以触发 Codex 内部内置的“专用智能体（Agents）”或“工作流启动器”。
