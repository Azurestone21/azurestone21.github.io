Codex 斜杠命令大全

Codex 斜杠命令大全

1. 核心控制与模型

管理 AI 模型、任务规划、状态监控和核心流程。

命令 功能 说明
/model 切换模型 更换当前使用的 AI 模型（如 /model gpt-4o）
/compact 压缩上下文 将对话内容总结为摘要，释放 Token 空间
/goal 设定目标 为当前会话明确一个高层次的任务目标
/plan 计划模式 进入逐步规划模式，分解复杂任务
/diff 查看改动 以 Git diff 风格展示所有文件变更
/recap 回顾摘要 生成当前会话的总结性回顾
/review 代码审查 触发专门的审查流程，分析代码改动
/status 查看状态 显示当前模型、Token 用量等会话信息
/stop 停止任务 立即终止正在进行的生成或运行任务

2. 会话管理

管理会话的生命周期：创建、删除、恢复、重命名等。

命令 功能 说明
/archive 归档会话 将当前会话存档，以便日后查阅
/clear 清空对话 清除当前会话历史，保留配置和上下文
/delete 删除数据 删除当前会话或指定数据（谨慎操作）
/exit 退出会话 退出当前交互式会话
/fork 分支会话 基于当前会话创建一个新的独立分支
/new 新建会话 创建一个全新的会话
/rename 重命名 修改当前会话的名称
/resume 恢复会话 恢复之前归档或中断的会话
/title 设置标题 为当前会话设定一个自定义标题

3. 文件与目录操作

与工作区文件、路径和内容相关的命令。

命令 功能 说明
/cd 切换目录 更改当前工作目录（类似 Shell 的 cd）
/copy 复制内容 将指定内容（如输出、代码块）复制到剪贴板
/export 导出数据 导出当前会话、配置或输出内容至文件
/import 导入数据 导入配置文件、会话快照或外部数据
/mention 提及文件 通过模糊搜索引用工作区中的文件或符号
/pwd 显示目录 显示当前工作目录的绝对路径
/raw 原始输出 以未格式化的原始形式显示输出内容

4. 沙箱与安全

控制权限、沙箱环境及安全相关设置。

命令 功能 说明
/approve 批准操作 批准待处理的权限请求或高风险操作
/permissions 权限管理 查看或修改各项操作所需的权限等级
/sandbox-add-read-dir 添加沙箱读目录 为沙箱环境增加可读取的额外目录
/setup-default-sandbox 设置默认沙箱 配置默认的沙箱环境参数（如网络、文件访问）

5. 界面与显示

控制终端界面外观、快捷键、主题等用户体验。

命令 功能 说明
/keymap 快捷键映射 查看或自定义键盘快捷键绑定
/pets 宠物功能 显示趣味宠物（娱乐性交互）
/side 侧边栏 打开或切换侧边栏视图（如文件树）
/statusline 状态行 自定义底部状态栏显示的内容
/theme 切换主题 更换终端界面的颜色主题
/vim Vim 模式 切换至 Vim 风格的键绑定（开/关）

6. 代理与技能

管理智能代理、子代理、记忆、个性等高级能力。

命令 功能 说明
/agents 管理代理 查看或配置当前可用的智能代理
/hooks 管理钩子 配置事件触发时自动执行的钩子脚本
/memories 管理记忆 查看或编辑持久化存储的记忆内容
/personality 个性设置 调整 AI 回复的语气、风格或角色
/skills 管理技能 查看、启用或配置自定义技能（Skill）
/subagents 管理子代理 配置或调用子代理来处理特定子任务

7. 集成与扩展

与外部工具、IDE、插件、MCP 等集成。

命令 功能 说明
/app 应用操作 打开或管理关联的外部应用程序
/ide IDE 集成 配置或启动与 IDE 的集成功能
/mcp MCP 管理 配置 Model Context Protocol 连接
/plugins 插件管理 列出、安装或卸载插件

8. 实用工具

其他杂项工具，如反馈、登出、实验功能等。

命令 功能 说明
/experimental 实验性功能 启用或查看正在实验中的功能列表
/feedback 提交反馈 向开发团队发送意见或问题报告
/init 初始化 在当前目录初始化项目或配置文件
/logout 登出 注销当前登录的用户账户
/ps 进程状态 显示当前运行中的进程或会话列表

注：部分命令的功能可能因 Codex 版本或插件而异，建议在终端中直接输入 /help 查看当前环境的完整命令列表和详细用法。
