JavaScript 基础实现

手写 call、apply、bind

call 和 apply 都是改变 this 并立即执行，区别是参数形式：call 逐个传，apply 传数组。
bind 返回一个新函数，不立即执行，支持柯里化参数，new 调用时 this 失效。
核心：把函数挂到目标对象上，用对象调用，再删除，避免污染。

  • 时间：O(1)（apply 展开参数为 O(k)，k 为参数个数）
  • 空间：O(1)

实现防抖（debounce）和节流（throttle）

防抖：事件触发后延迟执行，期间再次触发重新计时，适合搜索、resize。
节流：固定时间只执行一次，适合滚动、拖拽。
防抖重点：clearTimeout 重置，支持 immediate 首次立即执行。
节流重点：时间戳或定时器，支持首次和末次执行。

深拷贝（Deep Clone）

深拷贝递归复制所有层级，不共享引用。
要处理：基本类型、对象、数组、Date、RegExp、Map、Set、循环引用。
用 WeakMap 记录已拷贝对象，解决循环引用。
不可直接拷贝：函数、DOM、原型链复杂对象，按需处理。
简单场景可用 structuredClone，但兼容性和类型支持有限。

  • 时间：O(n)，n 为对象总节点数
  • 空间：O(n)，WeakMap + 递归栈（最坏深度为树高）

手写 new

new 做了四件事：

  1. 创建一个新对象。
  2. 把新对象的原型指向构造函数的 prototype。
  3. 以新对象为 this 执行构造函数。
  4. 如果构造函数返回的是对象/函数，就返回它；否则返回新对象。
  • 时间：O(1)（不含构造函数内部逻辑）
  • 空间：O(1)

手写 instanceof

原理：沿着对象的原型链向上查找，看能否找到构造函数的 prototype。

  • 时间：O(d)，d 为原型链长度
  • 空间：O(1)

实现 Promise（包括 Promise.all、Promise.race 等）

Promise 核心是状态机：pending、fulfilled、rejected，状态一旦改变不可逆。
用 then 收集回调，用微任务异步执行，支持链式调用。
Promise.all：全部成功才成功，一个失败就失败，结果按顺序返回。
Promise.race：第一个 settled 的结果就是最终结果。
Promise.allSettled：等全部结束，返回每个状态。
Promise.any：第一个成功就成功，全失败才失败。
手写重点：状态不可逆、回调队列、resolvePromise 处理 thenable、微任务调度。

数组与对象

数组扁平化（flatten）

扁平化是把嵌套数组变成一维数组。
实现：递归、reduce、栈、flat(Infinity)。
要控制深度，处理非数组元素，避免栈溢出可用迭代。

  • 递归版：时间 O(n)，空间 O(d)，d 为嵌套深度
  • 迭代版（unshift）：时间 O(n²)，空间 O(n)；改成 push + reverse 后时间为 O(n)

数组去重

去重方法：

  1. Set，最简单，适合基本类型；
  2. filter + indexOf；
  3. Map，支持对象按 key 去重；
  4. 对象数组按 id 去重。

Set 对 NaN、引用类型有细节，对象需要自己定义唯一键。

  • Set 版：时间 O(n)，空间 O(n)
  • 双重循环版：时间 O(n²)，空间 O(1)
  • uniqueBy：时间 O(n)，空间 O(n)

实现 map、filter、reduce 等数组方法

map：遍历，返回新数组，长度不变。
filter：遍历，返回满足条件的元素组成的新数组。
reduce：累加器，支持初始值，回调接收 acc、cur、index、arr。
注意：不改变原数组，处理稀疏数组和 thisArg。

  • 时间：O(n)
  • 空间：map / filter 为 O(n)，reduce 为 O(1)

手写 Object.assign

原理：把每个源对象的可枚举自有属性（含 Symbol）复制到目标对象，返回目标对象。

  • 时间：O(k)，k 为所有源对象可枚举属性总数
  • 空间：O(k)

函数

函数柯里化（Currying）

柯里化是把多参数函数变成一系列单参数函数。
核心：收集参数，参数够了就执行，不够就返回新函数继续收集。
好处：参数复用、延迟执行、组合函数。
面试常考：支持 add(1)(2)(3) 和 add(1, 2)(3)。

  • 时间：每次调用 O(1)
  • 空间：O(m)，m 为已收集参数个数

DOM 与事件

手写事件委托（Event Delegation）

事件委托是利用事件冒泡，把事件监听绑在父元素上，通过 event.target 判断实际触发元素。
优点：减少监听器数量、支持动态元素、节省内存。
适合列表、表格、菜单。
注意：target 可能是子元素，要用 closest 找到委托目标。
原理：把监听器绑定在父元素上，利用事件冒泡，在回调里通过 closest 找到实际触发元素，再调用处理函数。

  • 时间：绑定 O(1)；触发时 closest 向上查找 O(d)，d 为 DOM 深度
  • 空间：O(1)

手写 once 事件监听

原理：包一层 wrapper，执行完立即 removeEventListener。

  • 时间：O(1)
  • 空间：O(1)

实现简易 querySelectorAll

原理：深度优先遍历 DOM 树，用 matches 判断每个节点是否匹配选择器。

  • 时间：O(n)，n 为节点数
  • 空间：O(h)，h 为 DOM 深度（递归栈）

设计模式

设计模式是解决常见问题的可复用方案。
前端常考：

  1. 单例：全局唯一实例；
  2. 发布订阅：事件总线；
  3. 观察者：响应式；
  4. 工厂：创建对象；
  5. 策略：替换 if-else；
  6. 代理：缓存、拦截；
  7. 装饰器：增强功能；
  8. 适配器：兼容接口；
  9. 组合：树形结构统一处理。

面试重点：单例、发布订阅、观察者、策略、代理。

单例模式（Singleton）

单例保证一个类只有一个实例，并提供全局访问点。
实现：闭包缓存实例，或静态属性，或 ES Module 天然单例。
场景：全局状态、配置、弹窗、日志、连接池。

发布-订阅模式（EventEmitter）

发布订阅：发布者发事件，订阅者监听事件，通过事件中心解耦。
核心：on 订阅、emit 触发、off 取消、once 只执行一次。
和观察者区别：发布订阅有事件中心，观察者是目标直接通知观察者。
场景：EventBus、组件通信、消息队列。
原理：用 Map 存事件名到监听器数组的映射，on 添加、off 移除、emit 依次调用、once 包一层执行后自动移除。

  • on：时间 O(1)，空间 O(1)
  • off：时间 O(m)，m 为该事件监听器数量
  • emit：时间 O(m)
  • 总空间：O(监听器总数)

观察者模式（Observer）

观察者模式：目标-观察者关系，目标变化通知所有观察者。
场景：Vue 响应式系统。
原理：存目标到观察者数组，subscribe 添加、unsubscribe 移除、notify 依次调用。

手写简易版的 Vue 响应式系统

Vue 2 用 Object.defineProperty，Vue 3 用 Proxy。
核心：数据劫持 + 依赖收集 + 派发更新。
每个响应式属性对应一个 Dep，Watcher 订阅 Dep，数据变化通知 Watcher 更新。
简易版用 Proxy + effect + track + trigger。

实现 React Hooks

React Hooks 状态存在 Fiber 的 memoizedState 链表上，靠调用顺序匹配。
简易版可以用数组 + 索引模拟：

  • useState：返回当前状态和 setter；
  • useEffect：依赖变化才执行，支持清理；
  • 每次渲染重置索引。

真实实现要考虑 Fiber、双缓存、调度、批处理。
