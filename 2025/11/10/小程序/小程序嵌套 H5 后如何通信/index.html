H5 如何向小程序发消息

H5 端需要引入微信 JSSDK，然后调用 wx.miniProgram.postMessage。

关键限制：这条消息不会立即被小程序收到。它只是被暂存起来，必须等到用户触发“小程序后退、web-view 组件销毁、分享、复制链接”这些动作时，小程序的 bindmessage 事件才会被触发，并把之前积压的消息作为一个数组一次性传给小程序。

所以，如果你指望 H5 点个按钮，小程序立刻弹窗，用这个 API 是做不到的。它适合用来在用户离开页面或分享时，回传一些最终状态（比如分享参数、页面停留数据）。

两个容易踩的坑

1. 需要配置域名白名单
web-view 的 src 域名必须在微信公众平台后台的“开发管理 → 业务域名”里配置过。个人主体小程序不支持使用 web-view。域名必须是 HTTPS，且需要把校验文件放到域名根目录下。

2. 别把 postMessage 当实时通信用
很多人以为 H5 发了消息，小程序 bindmessage 马上就能收到，结果调试半天没反应。记住它的触发时机是“后退、销毁、分享、复制链接”。如果需要 H5 触发小程序跳转或调用原生能力（如扫码、支付），应该用 wx.miniProgram.navigateTo 等导航 API，或者通过 URL 跳转到特定的小程序页面来间接实现。
