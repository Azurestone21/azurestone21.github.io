【JS】null和undefined

核心区别：undefined 是”系统没给值”，null 是”你主动给了个空值”。

一、本质区别

维度 undefined null
含义 未定义、缺失 空值、有意置空
类型 "undefined" "object"（历史 bug）
转数字 NaN 0
转布尔 false false
转字符串 "undefined" "null"
是否关键字 不是（是全局属性，老代码可被赋值） 是（保留字，不能被赋值）
JSON.stringify 对象里会被忽略 保留为null

typeof null === "object" 是 1995 年实现时的 bug，因为 JS 最初用低位标记类型，null 的全 0 表示被误判为对象。这个 bug 因为兼容性永远修不掉了。

1. 为什么会有 void 0

这意味着用 undefined 做判断并不可靠。

2. void 0 的作用

void 是一个运算符，不可被覆盖，它对任意表达式求值后永远返回真正的 undefined。

因为 void 是关键字，不能被覆盖，所以 void 0 是 保证拿到真 undefined 的安全写法 。压缩工具（如 UglifyJS）也喜欢用它，因为 void 0 比 undefined 少 3 个字符。

3. 现在还需要吗？

  1. 现代环境 undefined 已只读，直接用即可；
  2. void 0 主要出现在压缩产物里。
  3. 另一用途：<a href="javascript:void(0)"> 阻止跳转。

七、实践建议

  1. 不要给变量显式赋 undefined。想表达”空”，用 null；undefined 留给系统自动产生。
  1. API / 函数返回值统一约定：要么统一用 null 表示”无结果”，要么统一用 undefined，别混。
  2. 判断空值用 == null（同时覆盖两者），或用 ??。
