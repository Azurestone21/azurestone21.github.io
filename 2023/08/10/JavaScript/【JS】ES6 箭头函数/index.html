十四、this 与作用域的再次强调

箭头函数的 this 是词法的，但箭头函数仍有自己的作用域。

  • this.x 走 this 绑定（外层 this）
  • x 走作用域链（全局）

两者独立。

十六、总结

核心特性：

  1. 词法 this：继承定义时外层的 this，不随调用方式改变。
  2. 没有 arguments：引用外层的，需要时用剩余参数。
  3. 不能 new：没有 [[Construct]] 和 prototype。
  4. 没有 prototype：不能用于继承。
  5. 不能 yield：不能做生成器。
  6. 没有 super / new.target。

语法要点：

  • 单参数可省括号，多参数/默认值/解构/剩余参数必须写括号。
  • 单表达式隐式返回，多语句用 {} + return。
  • 返回对象必须加 () 包裹。

使用建议：

  • 回调、Promise 链、需要保留外层 this 时 → 用箭头函数。
  • 对象方法、构造函数、需要动态 this、需要 arguments → 用普通函数。
  • class 字段箭头函数可避免 this 丢失，但有内存开销。

一句话记忆：

箭头函数是”没有自己的 this 和 arguments 的轻量函数”，它把 this 变成词法的。
