【JS】let，const和var

【JS】let，const和var

let、const 和 var 的核心区别，可以从你提到的三个方面来梳理：

1. 作用域

关键字 作用域
var 函数作用域（function scope），只在函数内有效；在函数外声明则是全局作用域
let 块级作用域（block scope），{}、if、for 等块内有效
const 块级作用域，同 let

2. 变量提升（Hoisting）

关键字 提升行为
var 声明被提升到作用域顶部，初始化为 undefined
let 声明被提升，但不初始化（处于 TDZ 中）
const 同let，声明被提升但不初始化

关键点：let/const 其实也有提升，只是提升后不会像 var 那样被赋值为 undefined，而是进入”暂时性死区”。

3. 暂时性死区（TDZ, Temporal Dead Zone）

TDZ 是 let/const 特有的概念：从进入作用域到声明语句执行之间的区域。

  • 在这段区域内访问变量会抛出 ReferenceError
  • 即使是 typeof 也会报错（var 则返回 "undefined"）

4. 其他相关差异

  • 重复声明：var 允许同一作用域重复声明；let/const 不允许。
  • 全局对象属性：全局 var 会成为 window 的属性；let/const 不会。
  • const 额外要求：声明时必须初始化，且不能重新赋值（但对象内部属性可改）。

5. 总结对比表（完整版）

特性 var let const
作用域 函数作用域 块级作用域 块级作用域
变量提升 提升，初始化为undefined 提升，但不初始化 提升，但不初始化
暂时性死区 无 有 有
重复声明 允许 不允许 不允许
必须初始化 否 否 是
可重新赋值 是 是 否
成为全局对象属性 是 否 否

6. 实践建议

  1. 默认用 const，只有需要重新赋值时才用 let。
  2. 基本不用 var，除非维护老代码。
  3. 需要真正不可变的对象，配合 Object.freeze()（注意浅冻结）。
  4. 记住 TDZ 是”进入作用域即开始”，不是”执行到声明行才开始”。

7. 相关面试题

1：for 循环里 var 和 let 的区别

为什么？

  • var 是函数作用域，整个循环只有一个 i，三个回调共享它。循环结束后 i 已经变成 3。
  • let 是块级作用域，每次迭代都会创建一个新的 i，每个回调捕获的是各自那一轮的 i。

补充：let 在 for 循环中的这个行为，规范里叫”每次迭代绑定”（per-iteration binding），可以理解为每轮循环都克隆了一份新变量，并把上一轮的值复制过去。

5：全局作用域下的差异

  • 全局 var 会挂到 window（全局对象）上。
  • 全局 let/const 存在于脚本顶层作用域（script scope），但不成为 window 属性。

这在实际开发中有个副作用：在浏览器控制台里，var 声明的变量能用 window.xxx 访问，let/const 不行。

6：typeof 在 TDZ 里也会报错

这是一个很多人不知道的细节：typeof 对完全未声明的变量返回 "undefined"，但对处于 TDZ 的变量会直接抛错。
