CSS 圆形轨迹布局与动画过渡

一、核心实现：圆周定位

1.1 基础公式

使用 transform: rotate(θ) translateX(R) 可以让元素精确分布在半径为 R 的圆周上。

原理：

  • 首先将元素定位到圆心（left/top 设为中心点坐标）。
  • rotate(θ)：绕圆心旋转 θ 度，确定方向。
  • translateX(R)：沿旋转后的 X 轴方向移动 R，落到圆周上。

最终坐标：(R·cosθ, R·sinθ)。

需要注意：rotate 和 translateX 不能调换顺序

rotate(θ) translateX(R) 与 translateX(R) rotate(θ) 在最终位置数学等价，但在配合内部容器进行内容回正时必须固定顺序。

当内部容器使用 rotate(-θ) 抵消旋转时：

  • 正确顺序：rotate(θ) translateX(R) + 内部 rotate(-θ) → 总变换为径向平移，卡片内容水平，位置正确。
  • 错误顺序：translateX(R) rotate(θ) + 内部 rotate(-θ) → 总变换为固定平移 (R,0)，所有卡片重叠。

1.2 保留内容正向

外层容器旋转后，内部文字/头像也会倾斜。解决方法：

  • 内层容器应用相反角度：transform: rotate(-θ)。
  • 使用 CSS 变量传递角度：--rank-counter-angle: -${angleDeg}deg。

二、旋转中心（transform-origin）的关键

2.1 默认行为

CSS 中 rotate 的旋转中心由 transform-origin 决定，默认值为自身的几何中心（cneter = 50% 50%）。

自身的几何中心是transform变化前的位置。

2.2 零宽高技巧

上面例子中，.rank-orbit 设置了 width: 0; height: 0;：

  • 元素没有尺寸，其几何中心与左上角重合。
  • 通过 left/top 将左上角固定在圆心 → 旋转中心 = 圆心。

如果元素有宽高（如 width: 96px），旋转中心会偏移到 (left+48px, top+22.5px)，导致圆周轨迹偏离。

2.3 修改 transform-origin

若必须保留宽高，可显式设置 transform-origin: 0 0;，让旋转中心回到左上角（即圆心位置）。但可能引起元素间重叠，不推荐。

三、平滑动画：CSS Transition

3.1 过渡属性

当角度 angleDeg 动态变化时（例如轮播下一张），transform 属性会触发 CSS 过渡动画，实现卡片沿轨道平滑移动。

3.2 CSS 变量控制时长

通过内联样式动态设置 --orbit-step-duration，可以实现不同场景下的动画速度（例如快速切换/慢速旋转）。

3.3 过渡效果的必要条件

  • 必须存在属性值的变化（如 transform 从 rotate(0deg) translateX(R) 变为 rotate(30deg) translateX(R)）。
  • 过渡元素需要设置 transition 属性。
  • 变化的属性必须在 transition 中列出（可使用 all 或具体指定 transform）。

3.4 性能提示

  • 使用 transform 而非 left/top 改变位置 → 利用 GPU 加速，避免重排（reflow）。
  • 添加 will-change: transform 提示浏览器提前优化。

五、常见误区与 FAQ

Q1：rotate(θ) translateX(R) 是先旋转还是先平移？

CSS 变换函数从右向左应用：先 translateX(R)（沿原始 X 轴），再 rotate(θ)（绕原点旋转）。所以直观上等同于“先确定方向再走半径”。

Q2：为什么不直接使用 left/top 计算位置？

  • transform 性能更好（GPU 合成层）。
  • transition 可以平滑过渡，而 left/top 变化会触发重排，动画卡顿。

Q3：内部容器 rotate(-θ) 会不会与父容器产生冲突？

不会，因为子元素的变换是在父元素变换后的坐标系中应用的。两者组合为：父矩阵 × 子矩阵，最终效果是纯平移 + 内容回正。

Q4：如何实现仅半圆弧可见（如正面显示，背面隐藏）？

可以通过判断 sin(θ) 的正负来设置 opacity 或 zIndex，配合可见角度范围过滤。例子中被注释的代码正是此用途。
