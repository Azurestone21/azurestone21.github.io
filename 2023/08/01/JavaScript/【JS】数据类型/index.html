【JS】数据类型

在 ECMAScript 规范里，JavaScript 的数据类型分为 8 种语言类型：

原始类型/基本类型：String、Number、Boolean、Undefined、Null、BigInt、Symbol
引用类型：Object

一、原始类型/基本类型

原始类型的特点是：按值访问、不可变、比较时比较值本身。

1. String

字符串是 UTF-16 代码单元组成的序列。

特点：

  • 不可变，所有字符串方法都不会改变原字符串；
  • 可以用单引号、双引号、反引号；
  • length 是代码单元数量，不是严格字符数量，某些 emoji 可能长度是 2。

注意：new String("abc") 是包装对象，类型是 object，不是原始字符串。

2. Number

JavaScript 的 number 是 IEEE 754 双精度 64 位浮点数，整数和小数都属于 number。

特殊值：

  • NaN：Not a Number，但类型仍是 number；
  • Infinity、-Infinity；
  • +0、-0。

4. Undefined

  • 表示未定义、未赋值、不存在

  • 有一个值：undefined。

  • 常见场景：

    • 变量声明了但没有赋值；
    • 函数没有返回值；
    • 访问对象不存在的属性；
    • void 0 的结果。

注意：undefined 通常表示“未定义/缺少值”。

undefined 不是保留字。在 ES5 之前，undefined只是全局对象的一个 普通属性 ，可以被改写。ES5 起，全局undefined 变成了只读属性。

5. Null

只有一个值：null，表示“空值/无对象”。

常见比较：

null 通常表示“故意置空”，undefined 通常表示“自然缺失”。

6. Symbol

ES6 新增，表示唯一且不可变的值，常用作对象属性键，避免命名冲突。

特点：

  • 不能 new Symbol()；
  • Symbol.for("key") 会在全局注册表中查找/创建；
  • Symbol.keyFor() 可获取全局 key；
  • 作为对象属性键时，不会出现在 Object.keys()、for...in 中，需要用 Object.getOwnPropertySymbols() 或 Reflect.ownKeys()。

7. BigInt

ES2020 新增，表示任意精度整数。

特点：

  • 字面量加 n；
  • 不能和 Number 混合进行算术运算；
  • 不能用于 Math 方法；
  • JSON.stringify(1n) 会报错；
  • 0n 是假值。

二、引用类型：Object

除了上面 7 种原始类型，其他都是 Object 类型。

包括：

  • 普通对象 {}；
  • 数组 []；
  • 函数 function(){}；
  • 日期 Date；
  • 正则 RegExp；
  • Map、Set；
  • Promise；
  • Error；
  • 包装对象：new Number()、new String()、new Boolean() 等。

函数本质也是对象，但 typeof 对函数返回 'function'，这是特殊处理。

引用类型的特点：

  • 按引用访问；
  • 变量保存的是引用地址；
  • 赋值时复制的是引用，不是对象本身；
  • 比较时比较引用地址，不是内容；
  • 可变，属性可以修改。

五、常见注意点

  1. typeof null === 'object' 历史遗留问题，不代表 null 是对象。
  2. **NaN !== NaN**判断 NaN 用 Number.isNaN()。
  3. **0.1 + 0.2 !== 0.3**浮点数精度问题。
  4. 原始类型不可变，引用类型可变字符串方法不会改原字符串，对象属性可以改。
  5. 包装对象
  6. BigInt 不能和 Number 混算
  7. Symbol 属性不会被普通遍历拿到
  8. null == undefined 为 true，但 null === undefined 为 false。
  9. const 声明的对象内容可以修改。

总结

JavaScript 数据类型可以记成：

7 种原始类型：undefined、null、boolean、number、string、symbol、bigint
1 种引用类型：object

核心区别：

维度 原始类型 引用类型
访问方式 按值 按引用
是否可变 不可变 可变
赋值 复制值 复制引用地址
比较 比较值 比较引用地址
常见类型 number/string/boolean 等 object/array/function 等

实际开发中重点注意：typeof null、NaN、浮点精度、== 隐式转换、BigInt 与 Number 不能混算、Symbol 作为属性键的特殊性。
