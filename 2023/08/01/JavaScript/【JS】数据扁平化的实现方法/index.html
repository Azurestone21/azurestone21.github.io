数据扁平化的实现方法

数据扁平化是指将嵌套的数组或对象转换为一维数组或对象。

一、数组

1. 使用ES6 Array.prototype.flat()（最推荐）

这是现代、简单且直接的方法。flat()方法会创建一个新数组，并根据指定深度递归合并所有子数组元素。

语法：arr.flat([depth])

  • depth（可选）：指定嵌套数组的提取深度，默认为1。
  • 若需完全扁平化，可传入Infinity。

优点：代码简洁、可读性高，是官方标准方法。
缺点：老旧浏览器可能不支持。

2. 使用递归

在flat()出现前，递归是标准实现思路。

思路：
遍历数组，若元素是数组则递归扁平化，合并结果；否则直接加入最终数组。

优点：兼容性好，逻辑清晰。
缺点：数组嵌套过深可能导致栈溢出。

3. 使用reduce+递归

递归方法的函数式写法，更精炼。

优点：代码紧凑，符合函数式编程风格。
缺点：同纯递归，存在栈溢出风险。

4. 使用迭代+栈（非递归）

通过栈模拟递归过程，避免栈溢出问题。

思路：

  1. 创建栈并放入原数组副本。
  2. 栈非空时弹出顶部元素。
  3. 若为数组，将其元素逆序入栈（保持顺序）。
  4. 若非数组，加入结果数组。
  5. 反转结果数组（因栈是后进先出）

五、注意点

  1. Array.prototype.flat 是 ES2019，旧浏览器需要 polyfill。
  2. flatMap 只能展开一层。
  3. 递归扁平化要注意循环引用，否则会死循环。
  4. JSON.parse(JSON.stringify()) 不适合做扁平化，会丢失 undefined、Symbol、Date、函数等。
  5. 对象扁平化通常用 . 拼接路径，也可以换成 /、_。
  6. 树形数据量大时，递归可能栈溢出，可以用栈迭代。

总结：

  • 数组：优先 arr.flat(Infinity) 或 flatMap
  • 对象：递归 + Object.entries 拼路径
  • 树：递归或栈遍历，移除 children 后 push
  • 兼容旧环境：递归 + reduce / 栈迭代
