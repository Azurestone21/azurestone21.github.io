【JS】包装对象

包装对象的核心作用：让原始值也能像对象一样访问属性和调用方法。
显式用 new Number()、new String()、new Boolean() 创建包装对象，实际开发中几乎不用，而且容易踩坑。

一、什么是包装对象

JS 有 7 种原始类型，其中 5 种有对应的包装对象：

原始类型 包装对象
string String
number Number
boolean Boolean
symbol Symbol
bigint BigInt

三、显式包装对象有什么用？

可以用 new 或 Object() 显式创建包装对象：

它们的作用：

  1. 历史遗留：早期 JS 设计时，为了让原始值也能统一成对象使用。
  2. 需要对象引用的场景：少数情况下需要一个对象而不是原始值。
  3. 类型判断：通过 Object.prototype.toString.call 可以区分。
  4. 临时给原始值加属性：但通常不推荐，不如直接用普通对象。

但实际开发中，几乎不需要这样做。

四、原始值 vs 包装对象

五、经典坑

1. new Boolean(false) 是真值

2. === 比较不相等

但 == 会触发类型转换，可能为 true：

3. typeof 变成 object

4. Symbol 和 BigInt 不能 new

Symbol 和 BigInt 是后来新增的类型，语言设计者吸取了教训：不希望开发者创建它们的包装对象，所以直接禁止 new。

这样保证：

  • Symbol() 永远返回原始值 symbol；
  • BigInt() 永远返回原始值 bigint；
  • 不会出现 new Symbol() 或 new BigInt() 等包装对象，避免类型判断混乱、真假值陷阱。

七、总结

包装对象的作用：

让原始值可以调用方法，这是 JS 自动装箱的底层机制。

显式包装对象：

历史遗留，实际开发几乎不用，而且有坑，不推荐。
