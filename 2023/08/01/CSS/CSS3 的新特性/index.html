CSS3 的新特性

CSS3

CSS3 是 CSS 的第三个主要版本，它把 CSS 从「样式表」推向了「表现层能力平台」，核心变化是模块化和新增大量视觉、布局、动画能力。

核心新增能力

1. 选择器增强

  • 属性选择器：[type="text"]
  • 伪类：:nth-child()、:nth-of-type()、:not()、:last-child
  • 伪元素：::before、::after、::selection
  • 关系选择器：~（兄弟）、>（子元素）

意义：减少对 class 和 JS 的依赖，选择更精准。

2. 盒模型与布局

  • box-sizing: border-box：让 width 包含 padding 和 border，布局计算更直观
  • Flexbox：一维布局，解决居中、等高、弹性分配等问题
  • Grid：二维布局，适合复杂页面结构
  • calc()：混合单位计算，如 calc(100% - 60px)

意义：布局从「float + position hack」进化到声明式布局。

3. 视觉表现

  • 圆角：border-radius
  • 阴影：box-shadow、text-shadow
  • 渐变：linear-gradient、radial-gradient
  • 背景：多背景、background-size、background-clip
  • 透明度：opacity、rgba()、hsla()
  • 滤镜：filter: blur() / grayscale()
  • 混合模式：mix-blend-mode

意义：以前要靠图片实现的视觉效果，现在 CSS 就能做。

4. 过渡与动画

  • Transition：transition: all 0.3s ease，状态间平滑过渡
  • Animation：@keyframes + animation，支持多关键帧、循环、方向控制
  • Transform：translate、rotate、scale、skew，2D/3D 变换

意义：交互动效不再依赖 JS 或 Flash，性能和可维护性都更好。

5. 响应式与媒体查询

  • @media：根据屏幕宽度、分辨率、方向应用不同样式
  • 相对单位：rem、em、vw、vh、vmin、vmax
  • 图片响应式：srcset、sizes（配合 HTML）

意义：一套代码适配多端成为可能，是移动优先开发的基础。

6. 字体与文本

  • @font-face：自定义字体
  • font-display：控制字体加载期间的显示行为
  • 文本效果：text-overflow: ellipsis、word-break、writing-mode

7. 其他新特性

  • CSS 变量：--main-color: #333; color: var(--main-color)
  • 自定义属性：支持运行时修改，主题切换很方便
  • 多列布局：column-count、column-gap
  • 形状：clip-path、shape-outside
  • 滚动行为：scroll-behavior: smooth
  • 容器查询：@container（较新，组件级响应式）

实际影响

CSS3 带来的不只是语法变化，而是让前端能独立完成更多事情：

  • 布局现代化：Flex/Grid 让复杂布局变得简单可控
  • 动效原生化：Transition/Animation 替代大量 JS 动画
  • 响应式普及：媒体查询 + 相对单位支撑移动优先
  • 主题化能力：CSS 变量让换肤、暗黑模式成本大幅降低
  • 视觉表现力：渐变、阴影、滤镜减少图片依赖，提升性能
