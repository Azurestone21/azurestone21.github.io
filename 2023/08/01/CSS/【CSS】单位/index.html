【CSS】单位

对比基准

这些单位的核心区别在于参照基准不同：px 是固定像素，em 相对父元素或自身字体，rem 相对根元素字体，vw/vh 相对视口，百分比相对包含块。

1. px（像素）

  • 绝对单位，固定像素值
  • 不随父元素、根元素、视口变化
  • 优点：精确、直观、计算简单
  • 缺点：不随用户字体设置缩放，响应式能力弱
  • 适合：边框、阴影、固定尺寸、不需要响应式的场景

2. em

  • 相对单位，基准是当前元素的 font-size
  • 用于 font-size 时，相对父元素的 font-size
  • 用于其他属性（如 margin、padding）时，相对自身的 font-size
  • 优点：可继承、可缩放，适合做组件内比例
  • 缺点：嵌套时层层相乘，容易失控
  • 适合：组件内部比例、图标字体、需要随字体缩放的间距

3. rem（root em）

  • 相对单位，基准永远是根元素 <html> 的 font-size
  • 不受父元素影响，没有嵌套相乘问题
  • 优点：全局统一、易预测、适合响应式
  • 缺点：需要设置根字体，否则默认 16px
  • 适合：字体、间距、整体尺寸的响应式缩放

常见用法：用媒体查询或 JS 调整根字体，实现整体缩放。

4. vw / vh（视口单位）

  • 相对单位，基准是视口
  • 1vw = 视口宽度的 1%
  • 1vh = 视口高度的 1%
  • 还有 vmin（取宽高较小值）、vmax（取较大值）
  • 优点：真正跟随屏幕尺寸，适合全屏布局
  • 缺点：移动端浏览器地址栏收放会导致 vh 变化，需注意
  • 适合：全屏区域、字体随屏幕缩放、大屏适配

移动端 vh 的坑：

移动端地址栏收起/展开时，100vh 会变化，导致布局跳动。可以用 100dvh（动态视口高度）替代，或 JS 动态计算。

5. 百分比 %

  • 相对单位，基准是包含块或父元素
  • 重点：
    • width、padding、margin 的百分比都相对包含块宽度
    • height 的百分比相对包含块高度，父元素高度 auto 时可能失效
    • font-size 的百分比相对父元素字体
  • 优点：弹性好，适合流式布局
  • 缺点：基准不统一，容易混淆；高度百分比常失效
  • 适合：宽度自适应、栅格、流式布局

对比表格

单位 参照基准 是否继承 响应式能力 典型场景
px 固定像素 否 弱 边框、固定尺寸

rem 根元素 font-size 是（统一） 强 字体、间距、整体缩放

实际选型建议

1. 字体

  • 推荐 rem：全局统一，方便响应式
  • 避免用 px 做字体，用户无法通过浏览器设置缩放
  • em 可用于组件内相对字体

2. 间距

  • 推荐 rem：与字体缩放一致
  • 固定间距（如边框内边距）可用 px

3. 布局宽度

  • 流式布局用 %
  • 全屏区域用 vw / vh
  • 栅格用 fr（Grid）或 flex（Flex）

4. 边框、阴影

  • 用 px：不需要缩放，保持视觉一致

5. 响应式方案

  • 移动端适配：rem + 动态根字体，或 vw + postcss-px-to-viewport
  • 整体缩放：rem 配合媒体查询
  • 全屏布局：vh / vw，注意 dvh 兼容

常见误区

误区一：em 和 rem 一样

不一样。em 相对自身或父元素字体，会嵌套相乘；rem 永远相对根元素字体，不会嵌套。

误区二：百分比高度总是有效

不是。父元素高度为 auto 时，子元素 height: 50% 可能失效，因为找不到参照高度。

误区三：vw 包含滚动条宽度

在桌面浏览器上，100vw 通常包含滚动条宽度，可能导致水平滚动。可以用 100% 或 calc(100vw - 滚动条宽度) 处理。

误区四：px 不能做响应式

可以，但需要配合媒体查询或 transform: scale。相比之下 rem、vw 更自然。

误区五：百分比 padding 相对高度

不是。padding 的百分比始终相对包含块宽度，即使是 padding-top 和 padding-bottom。

常见问题

问：em 和 rem 的区别？

em 相对当前元素或父元素的 font-size，嵌套时会层层相乘；rem 永远相对根元素 <html> 的 font-size，不会嵌套，更易预测。

问：百分比高度为什么经常失效？

因为 height 的百分比相对包含块高度，而父元素高度为 auto 时没有明确高度，百分比无法计算。解决方法是给父元素设明确高度，或用 vh、Flex。

问：移动端适配常用什么单位？

常用 rem + 动态根字体，或 vw + PostCSS 插件。也可以用 dvh 处理移动端视口高度问题。

问：vw 和 % 有什么区别？

vw 相对视口宽度，% 相对包含块宽度。vw 不受父元素影响，适合全屏；% 更灵活，适合流式布局。

问：px 和 rem 怎么选？

字体、间距、需要整体缩放的尺寸用 rem；边框、阴影、不需要缩放的固定尺寸用 px。
