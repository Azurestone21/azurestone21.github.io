【CSS3】Grid布局

CSS Grid 布局详解

CSS Grid（网格布局）是 CSS 中最强大的二维布局系统，能同时处理行和列。

一、核心概念

Grid 容器（Container） 和 Grid 项目（Item）：

容器内的直接子元素自动成为网格项目。

网格线（Grid Line）：划分网格的线，从 1 开始编号，也可从末尾 -1 倒数。
网格轨道（Track）：行或列。
网格单元（Cell）：行列交叉的最小单位。
网格区域（Area）：任意矩形区域。

五、Grid vs Flexbox 选择

场景 推荐
一维排列（一行或一列） Flexbox
二维网格（行列同时控制） Grid
整体页面骨架 Grid
导航栏、按钮组、垂直居中 Flexbox
卡片布局、仪表盘 Grid

两者可嵌套使用：Grid 做页面结构，内部用 Flex 做细节。

六、需要注意的坑

  1. fr 与内容最小宽度：1fr 默认最小值是 auto（内容撑开），要允许缩小用 minmax(0, 1fr)。
  2. 隐式网格影响布局：项目超出定义行列会自动生成，可能打乱预期，用 grid-auto-rows 控制。
  3. auto-fit vs auto-fill：前者空列塌缩（项目拉伸），后者保留空列。
  4. 命名区域必须矩形，不能 L 形。
  5. 子元素才参与网格，孙子元素不受影响（除非自己也 display:grid）。

七、浏览器支持

Grid 已获所有现代浏览器完整支持（包括 IE11 有旧版带前缀的 -ms-grid 语法，但功能受限）。移动端支持良好，可放心使用。
