Codex 中文乱码问题

背景

在使用 Codex 开发时，编写的代码中如果有中文，会显示乱码。后续让 Codex 解决起来比较耗时间。

原因

根本原因是终端编码问题。

Codex CLI 在 Windows 11 下运行默认在 PowerShell 中，默认的 PowerShell 版本为 5.1，Windows PowerShell 5.1 的编码默认为 GBK。
而Codex 默认使用 UTF-8 编码，经过 PowerShell 处理后，会显示乱码。

解决

关键是统一终端编码为 UTF-8。

安装 PowerShell 7.x

https://learn.microsoft.com/zh-cn/powershell/scripting/whats-new/migrating-from-windows-powershell-51-to-powershell-7?view=powershell-7.6

  1. 下载 PowerShell 7.x 安装包，双击打开，按照指引安装。
  2. 安装完成后，打开终端，看到的还是 Windows PowerShell，因为终端默认使用 Windows PowerShell。

  3. 打开“设置”，在“启动-默认配置文件”中，选择“PowerShell 7”。（默认可能是“PowerShell”，我这里重新命名了）

  4. 重新打开终端，看到的就是 PowerShell 7。
