异步请求 AJAX、Fetch、Axios

异步请求 AJAX、Fetch、Axios

这三个词经常一起出现，但它们不是同一层级的东西：

  • AJAX：一种技术思想/统称，不是具体库或 API。
  • Fetch：浏览器原生提供的现代 HTTP 请求 API。
  • axios：第三方 HTTP 请求库，浏览器和 Node.js 都能用。

一、概念介绍

1. AJAX

AJAX = Asynchronous JavaScript and XML，是一种技术思想/统称，不是具体 API。
核心：不刷新整个页面的情况下，用 JavaScript 向服务器发请求、拿数据、局部更新页面。
早期通常用 XMLHttpRequest（XHR）实现，现在也可以用 Fetch、axios 等实现。

AJAX 是“异步请求”这个概念，XHR、Fetch、axios 是具体实现方式。

2. Fetch

Fetch 是浏览器原生 API，基于 Promise，用于替代老旧的 XMLHttpRequest。
特点：原生、现代、轻量，但需要手动处理 JSON、HTTP 错误、超时、拦截器等。

3. axios

axios 是一个第三方 HTTP 请求库，浏览器和 Node.js 都能用。
特点：自动解析 JSON、非 2xx 自动 reject、支持拦截器、超时、取消请求、上传进度等。

三、错误处理

1. XHR

  • onerror：网络错误。
  • onload 中判断 xhr.status。
  • onabort：请求被取消。
  • ontimeout：超时（需设置 xhr.timeout）。

2. Fetch

  • 只有网络故障才会 reject，HTTP 404/500 不会 reject。
  • 需要手动判断 res.ok。
  • 取消错误：err.name === 'AbortError'。

3. axios

  • 非 2xx 自动 reject。
  • 错误对象包含 error.response、error.request、error.message。
  • 取消错误：axios.isCancel(err) 返回 true。

使用 xhr.abort()，取消后触发 onabort，readyState 变为 0，status 为 0。

4. 其他建议

  • 新项目一律使用 AbortController。
  • 维护旧项目时，若 Axios ≥ 0.22.0，建议逐步迁移到 AbortController。
  • 取消请求的错误要单独处理，避免误报。
  • 合理设置超时，提升用户体验。

七、总结

  • AJAX 是异步请求的统称；XHR 是旧的具体实现；fetch 是原生现代 API；axios 是功能全面的第三方库。
  • 基本使用：XHR 需手动处理，fetch 基于 Promise，axios 封装度最高。
  • 错误处理：XHR 靠事件和状态码，fetch 需判断 res.ok，axios 自动 reject 非 2xx。
  • 取消请求：XHR 用 abort()，fetch 用 AbortController，axios 推荐 AbortController，旧版用 CancelToken。
  • 三者对比：axios 功能最全，fetch 最轻量，XHR 最传统。
  • 最佳实践：防抖取消、组件卸载取消、重复请求取消、超时取消，统一使用 AbortController。

JAX 是概念，XHR 是旧实现，fetch 是原生现代 API，axios 是封装更好的第三方库。取消请求首选 AbortController。
