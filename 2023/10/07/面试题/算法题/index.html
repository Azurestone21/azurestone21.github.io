排序

冒泡排序

核心：相邻比较、大数后移

稳定

时间复杂度

  • 最坏情况：O(n²)，当列表是逆序时。
  • 最好情况：O(n)，当列表已经有序时。
  • 平均情况：O(n²)。

空间复杂度

  • O(1)，因为冒泡排序是原地排序算法，不需要额外的存储空间。

选择排序

核心：在未排序的序列中找到最小(或最大)元素，然后将其存放到序列的起始(末尾)位置。以此类推，直到所有元素均排序完毕。

不稳定

时间复杂度

  • 最坏情况：O(n²)，无论输入数据是否有序，都需要进行 n(n-1)/2 次比较。
  • 最好情况：O(n²)，即使列表已经有序，仍需进行相同数量的比较。
  • 平均情况：O(n²)。

空间复杂度

  • O(1)，选择排序是原地排序算法，不需要额外的存储空间

插入排序

核心：将一个元素插入到有序序列中，保持有序。

稳定

时间复杂度

  • 最坏情况：O(n²)，当列表是逆序时，每次插入都需要移动所有已排序元素。
  • 最好情况：O(n)，当列表已经有序时，只需遍历一次列表。
  • 平均情况：O(n²)。

空间复杂度

  • O(1)，插入排序是原地排序算法，不需要额外的存储空间。

快速排序

不稳定，交换时会改变元素的相对顺序。
核心思想：选基准，分区，递归左右

时间复杂度

  • 分解：每次将列表分成两半，需要 O(log n) 层递归。
  • 合并：每层递归需要 O(n) 的时间来合并子列表。
  • 总时间复杂度：O(n log n)。

空间复杂度

  • O(n)，归并排序需要额外的空间来存储临时列表。
  • 基础版，非原地版，空间开销大。
  • 原地版，Lomuto 分区

归并排序

稳定
核心：

  1. 分解（Divide）：将待排序的数组分成两个子数组，每个子数组包含大约一半的元素。
  2. 解决（Conquer）：递归地对每个子数组进行排序。
  3. 合并（Combine）：将两个已排序的子数组合并成一个有序的数组。

时间复杂度

  • 分解：每次将列表分成两半，需要 O(log n) 层递归。
  • 合并：每层递归需要 O(n) 的时间来合并子列表。
  • 总时间复杂度：O(n log n)。

空间复杂度

  • O(n)，归并排序需要额外的空间来存储临时列表。

树

二叉树遍历（前序、中序、后序）

二叉树遍历分深度优先和广度优先。
前序：根 → 左 → 右。
中序：左 → 根 → 右，二叉搜索树中序是升序。
后序：左 → 右 → 根。
实现分递归和迭代：递归简单，迭代用栈模拟，后序可用双栈或反转前序。
层序遍历用队列 BFS。
复杂度：时间 O(n)，空间 O(h)，h 是树高。

哈希

LRU 缓存

LRU 是最近最少使用淘汰策略，缓存满了优先淘汰最久未使用的。
要求 get 和 put 都是 O(1)。
核心结构：哈希表 + 双向链表。
哈希表存 key 到节点，双向链表维护使用顺序：头部最新，尾部最旧。
get 命中就移到头部；put 存在就更新并移到头部，不存在就插入头部，超容量删尾部。
JS 里可以用 Map 的插入顺序特性简化实现。

其他

二分查找

在有序数组中，每次取中间元素与目标比较，排除一半区间，直到找到目标或区间为空。

时间复杂度：O(log n)。
空间复杂度：O(1)。

多维数组转一维数组

时间复杂度：O(n)。
空间复杂度：O(n)。

合并两个有序数组

时间复杂度：O(m+n)。
空间复杂度：O(1)。
