【CSS】三大特性

CSS三大特性：继承、层叠性、优先级

一、继承

继承是祖先元素设置的样式，后代元素也会生效。遵顺“就近原则”

可继承属性

  • 字体： font-size、font-family、font-style、font、font-weight
  • 文本： color、text-align、text-indent、line-height、word-spacing、letter-spacing、text-transform
  • 列表布局：list-style、list-style-type、list-style-image、list-style-position 等
  • 光标：cursor 光标显示为何种形态
  • 可见性：visibility 控制元素显示和隐藏
  • 表格布局

不可继承属性

  • 盒子模型：display、margin、border、padding、width、height、min-height、max-height、min-width、max-width
  • 定位相关：position、left、right、top、bottom、z-index
  • 浮动：float、clear
  • 其它：background、overflow、table-layout、vertical-align、page-break-after、page-bread-before 和 unicode-bidi
  • a 标签的 color 值默认不继承

line-height 的继承性

  • 数值：直接继承值，例如50px
  • 比例：直接继承比例，例如2
  • 百分比：继承%百分比计算后的值

设置继承性

默认不继承的属性想要继承，可以把属性值设为inherit 。表示这个属性的值继承父元素的。

  • initial 设置属性值和浏览器默认样式相同
  • inherit 属性值默认继承父元素
  • unset 是关键字 initial 和 inherit 的组合，如果属性有继承性，则继承父元素，没有则为默认值

二、层叠性

所谓的层叠性是指多个 CSS 规则可以同时作用于同一个标签，效果叠加，并不完全覆盖。

css 的层叠性有两层含义：叠加和覆盖

不同选择器作用同一元素，不同属性会叠加，相同属性会覆盖 。

  • 叠加
    • 不同选择器作用于同一元素，不同属性会叠加作用于元素。
  • 覆盖
    • 遵顺原则：“就近原则” 和 “优先级”
    • 首先需要计算选择器的权重，最后以选择器权重高的为主。如果选择器权重相同，则写在后面的会覆盖写在前面的。

三、优先级

important > 内联 > ID > 类class > 标签 | 伪类 | 属性选择 > 伪对象 > 继承 > 通配符

选择器的类型 实例 选择器权重
!important div 无穷大
行内样式（style 属性中样式） style='color:red;' 1000
id 选择器 #id 0100
类class、伪类、属性选择器 .box、:hover、[type='text'] 0010
标签选择器、伪元素选择器 div、:::after、:::before 0001
通配符、子选择器、相邻选择器等 *、> 、+、~ 0000
继承的样式 0000

权重计算方式

用三位数 (a, b, c) 表示：

  • a = ID 选择器数量
  • b = 类、属性、伪类数量
  • c = 元素、伪元素数量

关键规则

  1. 同权重时，后写的覆盖先写的（层叠顺序）。
  2. !important 优先级最高，但会破坏可维护性，慎用。多个 !important 之间再按权重比较。
  3. 内联样式权重高于所有选择器，但低于 !important。
  4. 继承的样式优先级最低，任何直接命中的规则都能覆盖它。
  5. 通配符 *、组合符 > + ~ 不增加权重。
