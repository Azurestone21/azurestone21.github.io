JSONP 跨域技术

JSONP（JSON with Padding）是一种在跨域环境下获取数据的技术。它利用<script>标签不受同源策略限制的特性，通过动态创建脚本标签来绕过浏览器的跨域限制。

JSONP = 用函数”填充”JSON，名字来源于 JSON。但是 JSONP 和 JSON其实没什么关系，JSON 是数据格式，JSONP 是跨域方案。

核心原理

浏览器出于安全考虑，默认禁止网页向不同域名、端口或协议的服务器发起 AJAX 请求（同源策略）。但 <script>、<img>、<link> 等标签可以跨域加载资源。

为什么不直接返回JSON数据？

因为浏览器通过用 <script> 加载回来的内容，会被当作 JavaScript 代码直接执行，而不是当数据读取。

如果服务器直接返回 {"name": "张三", "age": 18}，浏览器加载这个 <script> 后，会把这段内容当 JS 代码执行。而 {"name": "张三", "age": 18} 单独作为一条 JS 语句时，会报错。在 JS 里，{ 开头会被解析成代码块（block），而不是对象。

加上 handleData(...) 后，浏览器会把这段内容当 JS 代码执行。

特点

优点 缺点
兼容性好，支持老浏览器 只能发 GET 请求
不受同源策略限制 安全性差，容易受 XSS 攻击
实现简单 无法获取 HTTP 状态码、错误处理困难

现状

由于安全问题和功能限制，JSONP 现在已经基本被 CORS（跨域资源共享）取代。CORS 支持所有 HTTP 方法、更安全、错误处理也更完善。JSONP 主要出现在一些老项目中，或者需要兼容非常老的浏览器时才会使用。
