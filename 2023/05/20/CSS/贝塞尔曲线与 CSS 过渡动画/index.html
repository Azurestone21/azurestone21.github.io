一、贝塞尔曲线简介

贝塞尔曲线（Bézier curve）是一种由多个控制点定义的参数化平滑曲线，广泛用于计算机图形学中描述形状与运动路径。

二、CSS transition 过渡属性

transition 是 CSS3 新增的属性，用于定义属性值变化时的平滑过渡效果。它是以下四个属性的简写：

  • transition-property – 要过渡的属性名
  • transition-duration – 过渡时长
  • transition-timing-function – 过渡的速度曲线
  • transition-delay – 延迟开始时间

三、预置过渡曲线与 cubic-bezier() 对应关系

CSS 内置了五种关键字，本质都是预定义好的三次贝塞尔曲线 cubic-bezier()。

关键字 效果说明 对应的 cubic-bezier() 值
ease 默认值，先慢后快再慢 cubic-bezier(0.25, 0.1, 0.25, 1)
linear 匀速运动 cubic-bezier(0, 0, 1, 1)
ease-in 慢进快出（加速） cubic-bezier(0.42, 0, 1, 1)
ease-out 快进慢出（减速） cubic-bezier(0, 0, 0.58, 1)
ease-in-out 两头慢，中间快 cubic-bezier(0.42, 0, 0.58, 1)

因此，通过自定义 cubic-bezier() 可以创造出任意动画曲线。

坐标系说明

  • 横坐标 (x)：时间进程，取值范围 固定为 [0, 1]（对应动画从 0% 到 100%）。超出范围会被 CSS 引擎忽略或取默认值。
  • 纵坐标 (y)：动画完成进度（0% → 100%）。允许超出 [0, 1] 范围，从而实现“回弹”或“过冲”效果。
