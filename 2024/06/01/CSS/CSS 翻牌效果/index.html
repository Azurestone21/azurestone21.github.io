CSS 翻牌效果

CSS 翻牌效果

核心要点：

  1. .card-container 设置 perspective —— 给子元素提供 3D 透视。
  2. .card 设置 transform-style: preserve-3d —— 让子元素保留在 3D 空间中，不被压平。
  3. .card-face 设置 backface-visibility: hidden —— 翻转后背对屏幕的那一面自动隐藏。
  4. .card-back 预先设置 rotateY(180deg) —— 让背面一开始就朝向后方，悬停时旋转父级 .card 显示背面。

如需点击切换而非悬停，把 :hover 换成 JS 切换一个 class 即可，样式逻辑完全一样。
