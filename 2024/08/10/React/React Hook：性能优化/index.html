React Hook：性能优化Hook

React Hook：性能优化Hook

一、概述

useMemo 和 useCallback 都是 React 提供的性能优化 Hook，用于在组件重新渲染时缓存值或函数，避免不必要的计算和引用变化。

它们不是必须使用的。React 本身渲染很快，大多数场景不需要手动优化。只有在遇到性能问题，或需要稳定引用时，才考虑使用。

注意：React 不保证缓存永久有效。出于内存等原因，React 可能丢弃之前缓存的值，下次渲染重新计算。

二、useMemo

1. 作用

useMemo 用于缓存计算结果。依赖不变时，直接返回上次的计算结果；依赖变化时，重新计算。

2. 语法

  • 第一个参数：计算函数，必须纯，不能有副作用。
  • 第二个参数：依赖数组。
  • 返回值：缓存的计算结果。

3. 依赖数组行为

4. 适用场景

  • 昂贵计算：排序、过滤、聚合、复杂派生数据。
  • 稳定对象或数组引用：传给 React.memo 子组件，或作为其他 Hook 的依赖。
  • 避免因引用变化导致 useEffect 重复执行。

5. 示例

6. 注意事项

  • 计算函数在渲染期间执行，不能有副作用。
  • 依赖数组必须完整，否则会使用旧值。
  • 不要缓存很便宜的计算，缓存本身也有成本。
  • 不要用 useMemo 替代 useEffect。

三、useCallback

1. 作用

useCallback 用于缓存函数引用。依赖不变时，返回同一个函数；依赖变化时，返回新函数。

2. 语法

  • 第一个参数：要缓存的函数。
  • 第二个参数：依赖数组。
  • 返回值：缓存的函数。

3. 依赖数组行为

4. 适用场景

  • 将函数传给 React.memo 子组件，避免子组件因函数引用变化而重渲染。
  • 函数作为 useEffect、useMemo、其他 useCallback 的依赖。
  • 自定义 Hook 返回稳定函数。

5. 示例

如果 handleClick 不用 useCallback，每次 Parent 重渲染都会创建新函数，Child 的 React.memo 浅比较失败，导致 Child 重新渲染。用了 useCallback 且依赖不变，Child 可以跳过重渲染。

6. 注意事项

  • useCallback 只缓存函数引用，不执行函数。
  • 依赖数组必须完整，否则函数内部会捕获旧值。
  • 如果子组件没有用 React.memo，useCallback 通常不能减少子组件重渲染。
  • 不要包裹所有事件处理函数，只有明确需要稳定引用时才用。

四、两者关系与区别

1. 关系

useCallback 可以看作 useMemo 缓存函数的语法糖。

2. 区别

维度 useMemo useCallback
返回值 任意值 函数
缓存内容 计算结果 函数引用
等价写法 useMemo(() => value, deps) useMemo(() => fn, deps)
主要用途 昂贵计算、稳定对象/数组引用 稳定函数引用
常见配合 React.memo 子组件、其他 Hook 依赖 React.memo 子组件、其他 Hook 依赖
是否执行函数 是，在渲染期间执行计算函数 否，只返回函数

3. 一句话记忆

  • useMemo 缓存值。
  • useCallback 缓存函数。
  • useCallback(fn, deps) 就是 useMemo(() => fn, deps)。

五、与 React.memo 的配合

React.memo 会对 props 做浅比较。如果 props 中有对象、数组或函数，父组件每次重渲染都会创建新引用，导致 React.memo 失效。

这时需要：

  • 对象/数组用 useMemo 稳定引用。
  • 函数用 useCallback 稳定引用。

六、使用原则与注意事项

  1. 不要过早优化：先写清晰代码，遇到性能问题再优化。
  2. 不要滥用：缓存有成本，依赖比较和内存都有开销。
  3. 依赖数组必须完整：否则会捕获旧闭包，导致 bug。
  4. 不要在里面做副作用：useMemo 在渲染期间执行，副作用应用 useEffect。
  5. React 不保证缓存永久有效：缓存可能被丢弃，不能依赖它做语义保证。
  6. 没有 React.memo 时，useCallback 效果有限：父组件重渲染默认会带动子组件重渲染。
  7. React Compiler：现代 React 正在通过 React Compiler 自动做记忆化，未来手动使用 useMemo / useCallback 的场景会减少。

七、总结

  • useMemo：缓存计算结果，依赖不变时返回上次的值。
  • useCallback：缓存函数引用，依赖不变时返回同一个函数。
  • 两者都是性能优化手段，不是必须使用。
  • useCallback(fn, deps) 等价于 useMemo(() => fn, deps)。
  • 常见用途：配合 React.memo、稳定 Hook 依赖、避免昂贵计算。
  • 关键原则：先测量，再优化；需要稳定引用时才用。
