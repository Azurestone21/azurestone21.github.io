React useState Hook

React useState Hook

一、概述

useState 是 React 最基础的 Hook，用于让函数组件拥有自己的状态。状态变化后，React 会重新渲染组件。

基本语法

  • state：当前状态值。
  • setState：更新状态的函数。
  • initialState：初始值，可以是数字、字符串、布尔、对象、数组、null 等。
  • initialState 只在首次渲染时使用，后续渲染会忽略。

三、注意

1. 状态更新是异步、批处理的

调用 setState 后，当前代码里的 state 不会立刻变成新值：

在一次执行上下文中多次调用 setState，React 不会立刻渲染多次，而是合并成一次重新渲染。
React 18 之后，在事件、setTimeout、Promise、原生事件中都会自动批处理多个状态更新。

2. 每次渲染中的 state 是快照

同一次渲染里，state 是固定值，不会因为调用 setState 而改变。

依赖旧状态时要用函数式更新。

3. 必须遵守 Hooks 规则

  • 只在函数组件或自定义 Hook 的顶层调用。
  • 不要在条件、循环、嵌套函数中调用。
  • 每次渲染调用顺序必须一致。

4. setState 不会自动合并对象

useState 的 setter 会替换整个状态，而不是像类组件 setState 那样自动合并。

5. 不要直接修改对象或数组

React 通过引用比较判断状态是否变化。直接修改原对象或数组，通常不会触发正确更新。

6. 不要存能计算出来的值

如果某个值可以由现有 state 或 props 算出来，通常直接计算即可，不必再存一份 state。

7. 初始值只在首次渲染使用

后续重新渲染时，0 不会再次作为初始值。初始值只在组件第一次挂载时生效。

8. 复杂状态可考虑 useReducer

如果多个状态总是一起更新，或者更新逻辑复杂，可以考虑 useReducer 或状态管理库。

四、总结

  • 用 setState 更新状态，触发重新渲染。
  • 依赖旧状态时用 setState(prev => ...)。
  • 状态更新是异步、批处理的。
  • 对象和数组要不可变更新。
  • 初始值计算复杂时用惰性初始化。
  • 必须在组件顶层调用，遵守 Hooks 规则。
  • setState 不会自动合并对象。
  • 能计算出来的值不要存成 state。

一句话：useState 让函数组件拥有状态，但状态更新要按 React 的规则来，尤其是不可变更新和函数式更新。
