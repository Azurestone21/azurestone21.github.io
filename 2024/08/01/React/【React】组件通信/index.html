【React】组件通信

【React】组件通信

  1. 父传子：props；
  2. 子传父：父传回调函数，子组件调用回调；
  3. 兄弟：状态提升到公共父组件；
  4. 跨层级：Context、useContext；
  5. 全局状态：Redux、MobX、Zustand、Jotai、Recoil；
  6. ref 通信：useRef + forwardRef + useImperativeHandle，父调子方法；
  7. 事件总线：mitt、EventEmitter，React 官方不推荐；
  8. Portal：跨 DOM 但仍在 React 树，Context 和事件冒泡按 React 树走；
  9. URL / 路由：React Router 的 params、query、state；
  10. 服务端 / 缓存：React Query、SWR 共享服务端状态。

原则：能 props 就 props，跨层级用 Context，全局复杂状态用状态库，少用事件总线和 ref 通信。

一、父传子：props

最基础方式。

特点：

  • 单向数据流；
  • 子组件只读；
  • 可传值、函数、children、render props。

二、子传父：回调函数

父组件传函数，子组件调用。

特点：

  • React 官方推荐；
  • 本质还是 props；
  • 保持单向数据流。

三、兄弟组件：状态提升

把状态放到公共父组件。

特点：

  • 简单直接；
  • 父组件变成“状态中心”；
  • 层级深时容易 props drilling。

四、跨层级：Context

用 createContext + useContext。

适合：

  • 主题；
  • 语言；
  • 登录用户；
  • 全局配置。

注意：

  • Context 值变化会导致所有消费者重新渲染；
  • 大对象要 memo，或拆多个 Context；
  • 不适合高频变化的状态。

五、全局状态：Redux、MobX、Zustand、Jotai

适合跨组件、跨页面共享复杂状态。

对比：

  • Redux：规范强，适合大型项目，样板多；
  • Zustand：轻量，API 简单，推荐；
  • Jotai / Recoil：原子化，细粒度更新；
  • MobX：响应式，适合复杂对象。

六、ref 通信：父调子

父组件通过 ref 调用子组件方法。

React 19 中函数组件可以直接接收 ref，不需要 forwardRef。

适合：

  • 聚焦、滚动、播放；
  • 调用子组件命令式方法；
  • 集成第三方 DOM 库。

注意：

  • 破坏单向数据流；
  • 能用 props 就不用 ref。

七、事件总线：mitt

特点：

  • 简单跨组件；
  • 事件来源不清晰；
  • 难调试、易内存泄漏；
  • React 官方不推荐，中大型项目用状态库。

八、Portal

Portal 把子节点渲染到其他 DOM 位置，但在 React 树中仍属于原父组件。

特点：

  • Context 可访问；
  • 合成事件按 React 树冒泡；
  • 适合 Modal、Tooltip、Dropdown；
  • 不是专门的通信方式，但影响通信行为。

九、路由传参

React Router：

适合：

  • 页面间传参；
  • 分享 URL；
  • 刷新保持状态。

注意：

  • state 刷新会丢；
  • 敏感信息不要放 URL。

十、服务端状态：React Query、SWR

特点：

  • 缓存、去重、自动刷新；
  • 多个组件共享同一份服务端数据；
  • 不算传统组件通信，但实际项目常用。

十一、方式对比

方式 场景 优点 缺点
props 父子 简单、单向 层级深麻烦
回调 子传父 官方推荐 层级深麻烦
状态提升 兄弟 直观 父组件臃肿
Context 跨层级 避免 props drilling 值变化全量渲染
状态库 全局复杂 可维护、可调试 学习成本
ref 父调子 命令式控制 破坏数据流
事件总线 简单跨组件 灵活 难维护
Portal 弹窗浮层 解决层叠 非通信专用
路由 页面间 URL 可分享 state 刷新丢
React Query 服务端状态 缓存共享 只适合服务端数据

十二、常见问题

  • Context 和 Redux 区别？ Context 传值，Redux 管理状态和更新逻辑。
  • Context 值变化会怎样？ 所有消费者重新渲染，需要拆分或 memo。
  • 为什么不用事件总线？ 事件来源不清晰，难调试，易泄漏。
  • ref 能传值吗？ 能，但推荐 props，ref 用于命令式操作。
  • 兄弟组件怎么通信？ 状态提升到父组件，或全局状态。
  • React 19 ref 有什么变化？
    函数组件可直接接收 ref，不再必须 forwardRef。
