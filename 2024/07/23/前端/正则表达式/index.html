正则表达式

一、正则概念

1. 正则是什么

正则表达式是描述字符串匹配模式的语法，用于：

  • 校验：手机号、邮箱、密码
  • 查找：关键词高亮、提取版本号
  • 替换：千分位、模板变量、下划线转驼峰
  • 分割：query、路径、日志

核心认知：
正则是模式匹配工具，不是解析器。 不适合解析 HTML、JSON、复杂嵌套结构。

2. 正则引擎

常见分两类：

  • DFA：线性时间，不支持反向引用、断言等。
  • NFA：支持更多语法，但可能回溯，存在性能问题。

JS、Python、Java、PCRE 大多属于 NFA 类。
JS 正则可能发生 灾难性回溯。

3. 贪婪 vs 非贪婪

  • 贪婪：* + ? {n,m} 默认尽量多匹配。
  • 非贪婪：加 ?，如 *? +? ?? {n,m}?，尽量少匹配。

二、基础规则速查

1. 字符类

语法 含义
. 任意字符，默认不含换行
\d 数字[0-9]
\D 非数字
\w 字母、数字、下划线[A-Za-z0-9_]
\W 非\w
\s 空白字符
\S 非空白
[abc] a、b、c 任意一个
[^abc] 不是 a、b、c
[a-z] a 到 z
[\s\S] 任意字符，包括换行
[^] JS 中任意字符，包括换行

注意：
JS 的 \w、\d 默认不匹配中文和 Unicode 数字。
匹配中文可用 \p{Script=Han} + u。

2. 量词

语法 含义
* 0 次或多次
+ 1 次或多次
? 0 次或 1 次
{n} 正好 n 次
{n,} 至少 n 次
{n,m} n 到 m 次
*? 非贪婪，尽量少
+? 非贪婪，尽量少

3. 锚点与边界

语法 含义
^ 字符串开头，m 模式下为行开头
$ 字符串结尾，m 模式下为行结尾
\b 单词边界
\B 非单词边界

4. 分组与引用

语法 含义
(...) 捕获组
(?:...) 非捕获组
(?<name>...) 命名捕获组
\1 反向引用第 1 个捕获组
\k<name> 反向引用命名组

5. 零宽断言

语法 含义
(?=...) 正向前瞻：后面必须是什么
(?!...) 负向前瞻：后面不能是什么
(?<=...) 正向后顾：前面必须是什么
(?<!...) 负向后顾：前面不能是什么

六、性能与陷阱

1. 灾难性回溯

嵌套量词在匹配失败时可能指数级回溯，导致页面卡死。避免：

  • 少写嵌套量词。
  • 尽量具体，如 \d{1,3} 代替 .*。
  • 大文本避免复杂正则。
  • JS 不支持原子组和占有量词，可用前瞻模拟，但复杂场景建议换算法。

2. 不要用正则解析 HTML / JSON

HTML、JSON 是嵌套结构，正则不可靠。前端应使用：

  • DOMParser
  • innerHTML + 浏览器解析
  • 专门的 parser
