Android Studio 安装与使用

Android Studio 安装与使用

安装 Android Studio

https://developer.android.com/studio/index.html

  • 安装 Android Studio安装包（一直”下一步”）

安装 Android SDK

  • 启动 Android Studio
  • 按照文档安装 SDK Manager 里面的选项

  • 配置环境变量

    • 变量名：ANDROID_HOME
    • 变量值：使用上面的路径

  • 把工具目录添加到环境变量 Path

打包AKP

方式一：react-native bundle 执行

在项目根目录\android\app\src\main下新建assets文件夹

在项目根目录执行以下打包命令

生成签名密钥（如果还没有）

使用keytool命令（Java SDK中包含）来生成密钥库（keystore）。

按提示输入密钥库密码、你的名字、组织单位等信息。

生成的证书在SDK的bin目录里面

查看证书

口令：123456

将签名证书my-release-key.keystore放到到 android/app目录下。

配置gradle

  • 项目根目录android/gradle.properties文件中添加签名信息。
  • 项目根目录android/app/build.gradle文件，添加签名配置。

打包APK

执行完毕后，会在android/app/build/outputs/apk/release目录下生成APK文件。

  1. 此处的./，在有些命令行工具中会报错，例如cmd。可以尝试将./去掉重新执行命令.
  2. 我们将rn的版本从0.67升级到0.72之后出现了一些三方依赖在打包时报错的情况, 我们将命令更换成了./gradlew app:assembleRelease之后解决了这一问题

问题

Could not resolve all files for configuration ‘:app:releaseRuntimeClasspath’.

在设备上运行该发行版本

报错

The project is using an incompatible version (AGP 8.6.0) of the Android Gradle plugin. Latest supported version is AGP 8.0.2

AGP(Android Gradle Plugin) - Android Gradle 插件

  • Gradle版本和Gradle插件的版本不一致；
  • Android Studio版本和Gradle插件的版本不一致；

解决：需要安装新版本Andriod Studio
