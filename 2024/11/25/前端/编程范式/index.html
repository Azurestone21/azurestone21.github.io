命令式编程（Imperative Programming）

通过一系列命令或语句描述程序的执行步骤，程序员需要明确指定程序的每个细节，包括数据存储、计算顺序以及控制流程。

核心思想是将程序视为一系列按特定顺序执行的指令，通过这些指令实现程序功能。

程序的执行顺序是显式指定的：从顶部开始，按代码顺序逐行执行，直到遇到条件语句或循环语句等控制流程语句。这些语句可以改变执行路径，使程序能够根据不同的条件做出不同决策。

命令式编程的一个重要特点是状态的改变。程序中的变量可以被赋予不同的值，从而改变程序状态。这种改变通过赋值语句实现，程序员可以根据需要修改变量的值，以达到所需的计算结果。

优点：

  • 直观且易于理解：程序的执行顺序明确，程序员可以清楚地知道每个语句的执行顺序和效果，使调试和修改程序相对容易。

缺点：

  • 代码较为冗长：需要大量语句来描述程序的执行步骤。

声明式编程（Declarative Programming）

将重点放在描述问题的逻辑和约束上，而非详细说明解决问题的步骤。

最常用的 HTML 和 CSS 就属于声明式编程：通过 HTML 声明网页中包含哪些元素，通过 CSS 描述指定元素的样式。HTML 和 CSS 本身并不负责将元素渲染到页面上，只是描述想要的结果，由浏览器根据这些内容负责渲染。

SQL 也是一种声明式编程语言。使用 SQL 查询数据库时，可以用声明式的方式描述所需的数据，而不需要关心具体的查询过程。

优点：

  • 可读性高：更接近自然语言，代码更易于理解和阅读，程序员可以更容易地理解代码的意图和逻辑。
  • 可维护性高：关注于描述问题的逻辑和约束，而非实现细节，因此代码更易于维护。需求变化时，只需修改描述，而不需要修改实现步骤。
  • 代码复用性高：鼓励将逻辑和约束抽象为可重用的组件或函数，减少重复代码的编写，提高代码复用性。
  • 抽象级别高：提供了更高的抽象级别，使程序员能够更容易地表达复杂的逻辑和约束，代码更简洁、可读性更高，减少了出错的可能性。

缺点：

  • 灵活性受限：通常更适用于解决特定类型的问题，对于需要精确控制和灵活性的问题可能不太适用。在某些情况下，命令式编程可能更灵活、更高效。
  • 学习曲线较陡：对于习惯于命令式编程的开发人员来说，学习和适应声明式编程的思维方式可能需要一些时间和努力。
  • 性能问题：在某些情况下，声明式编程可能导致性能问题。由于程序员不直接控制实现细节，可能无法对性能进行优化。

面向过程编程（Procedural Programming）

以过程或函数为基本单位，通过顺序执行一系列操作来解决问题。

在面向过程编程中，程序的主要组成部分是过程或函数。过程是一组有序的语句块，用于执行特定任务。这些过程可以接受输入参数并返回输出结果。程序通过按一定顺序调用这些过程来实现特定功能。

面向过程编程将数据和过程分离，过程只关注如何处理数据，而不关心数据的具体内容。

例如封装一个方法，调用者只需传入数据，就可以得到结果。平时写的大部分代码都是面向过程的。

面向对象编程（Object-Oriented Programming，OOP）

将问题分解为对象的集合，每个对象具有属性和方法，通过对象之间的交互来解决问题。

重要特性：封装、继承、多态

  • 封装：将各种数据和操作封装到一个对象中。对象提供接口供外部访问和操作数据，隐藏了对象的内部细节，提高了数据的安全性和代码的可维护性。
  • 继承：一个类可以从另一个类派生出来，继承父类的属性和方法，并可以在此基础上进行扩展或修改。继承可以实现代码的重用和扩展，减少代码的冗余性。
  • 多态：允许子类重写父类的某些方法，允许不同的对象对同一消息做出不同的响应，提高了代码的灵活性和可扩展性。

前端第三方库大部分都是基于面向对象编程的，如 Vue、React、jQuery、ECharts。

函数式编程（Functional Programming）

函数式编程将计算视为数学函数的求值过程。在函数式编程中，函数被视为一等公民，可以作为参数传递给其他函数，也可以作为返回值返回。函数式编程强调使用纯函数，即没有副作用的函数，它们只依赖于输入参数并产生确定的输出结果。

函数是一等公民

特点：

  • 函数可以被赋值给变量
  • 函数可以作为参数传递
  • 函数可以作为返回值返回
  • 函数可以存储在数据结构中

函数作为一等公民的概念使得函数可以像其他数据类型一样被操作和传递，这为函数式编程提供了强大的能力。可以更灵活地组织和抽象代码，实现更高级的编程技巧，如高阶函数、函数组合和柯里化等。同时，函数作为一等公民也促进了代码的可读性、可维护性和可测试性。

纯函数

纯函数是指在相同的输入条件下，总是返回相同的输出结果，并且不会对外部环境产生任何副作用的函数。

纯函数不会修改传入的参数，也不会改变全局变量或者调用其他不纯的函数。它们只依赖于输入参数，而不依赖于外部的状态或者数据。

特点：

  • 输入不变，输出不变
  • 不依赖外部，只依赖参数
  • 没有副作用

副作用

  • 修改参数
  • 修改全局的值或者外部变量
  • 进行网络请求
  • 进行 DOM 操作
  • 调用定时器
