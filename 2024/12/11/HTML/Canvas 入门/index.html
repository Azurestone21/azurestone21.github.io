Canvas 入门

canvas 标签用来定义图形容器，但必须使用脚本来绘制图形。

canvas 是一个二维网格。

  1. 使用 <canvas>，需要设置 id、width 和 height。id 用于脚本引用，width 和 height 属性定义的画布的大小。
  2. JS 通过 id 获取canvas元素。
  3. getContext 创建 context 对象。
  4. 使用 context 对象的方法进行绘画。
