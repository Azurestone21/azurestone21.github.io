【JS】Object和Map的区别

概述

通常这里说的是 JavaScript 中的 Map 和普通对象 Object。

  • Object：本质是“属性集合”，键只能是 字符串 / Symbol。
  • Map：是专门的“键值对集合”，键可以是 任意类型，并且有 size、可迭代、增删更方便。

区别

维度 Object Map
键类型 只能是string 或 symbol 任意类型：对象、函数、数字、NaN 等
键转换 非字符串键会被转成字符串，如对象变成"[object Object]" 不转换，按引用 / SameValueZero 比较
大小 没有直接size，要 Object.keys(obj).length 有map.size
迭代 默认不可迭代，需要Object.keys/values/entries 可直接for...of，默认迭代 [key, value]
顺序 整数键升序，其他键按插入顺序 严格按插入顺序
原型 有原型链，可能继承属性，需注意hasOwnProperty 键不会和原型冲突，更安全
增删查 obj.k、delete obj.k、in map.set/get/has/delete/clear
JSON 可直接JSON.stringify(obj) 不能直接序列化，需要转成数组或对象
适用场景 结构化数据、配置、JSON、字符串键 字典、频繁增删、任意类型键、需要size / 迭代

如何选择

  • 用 Map：

    • 键不是字符串 / Symbol
    • 需要频繁增删键值对
    • 需要 size
    • 需要按插入顺序迭代
    • 想避免原型污染

  • 用 Object：

    • 表示实体、配置、JSON 数据
    • 键是字符串 / Symbol
    • 需要点语法、解构、JSON.stringify
    • 需要 getter / setter 等属性特性

简单说：Object 更适合表达“一个东西有哪些属性”，Map 更适合当“字典 / 哈希表”用。
