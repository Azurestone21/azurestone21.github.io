Vue 响应式原理

Vue 响应式原理

目标：理解 Vue 如何做到数据变化时自动更新视图。
核心思想：依赖收集 + 派发更新（发布订阅模式）。
Vue 2 用 Object.defineProperty，Vue 3 用 Proxy。

一、整体概念

Vue 的响应式系统解决一个问题：

当数据变化时，如何知道哪些地方用到了这个数据，并自动更新它们？

答案分三步：

  1. 数据劫持：把普通数据变成响应式数据，拦截读写。
  2. 依赖收集：读取数据时，记录“谁在用我”。
  3. 派发更新：修改数据时，通知所有“用我的地方”重新执行。

“谁”通常是一个 effect（副作用函数），比如组件渲染、computed、watch。

二、Vue 2 响应式原理

1. 核心流程

  1. 数据劫持
    递归遍历 data，用 Object.defineProperty 把每个属性转成 getter/setter·。
  2. 依赖收集
    组件渲染时创建 Watcher，读取数据触发 getter，把 Watcher 收集到该属性的 Dep 中。
  3. 派发更新
    数据变化触发 setter，调用 dep.notify()，通知所有 Watcher。
  4. 更新视图
    Watcher 收到通知后，重新执行渲染函数，更新 DOM。

2. 核心 API：Object.defineProperty

  • Dep：依赖收集器，内部有一个 subs 数组存放 Watcher。
  • Watcher：观察者，组件渲染、computed、watch 都会创建 Watcher。
  • Dep.target：全局变量，指向当前正在执行的 Watcher。

4. 缺点

  • 无法监听新增/删除属性，需要 Vue.set / Vue.delete。
  • 无法监听数组索引和 length 的直接修改。
  • 初始化时递归遍历所有属性，性能开销大。
  • 不支持 Map、Set 等数据结构。

三、Vue 3 响应式原理

1. 核心流程

  1. Proxy 代理
    用 Proxy 代理整个对象，拦截 get、set、deleteProperty、has、ownKeys 等操作。
  2. 依赖收集
    在 get 中调用 track(target, key)，把当前 effect 收集到依赖表中。
  3. 派发更新
    在 set 中调用 trigger(target, key)，取出依赖并执行对应的 effect。
  4. 惰性递归
    只有访问到嵌套对象时才递归代理，提升初始化性能。

2. 核心 API：Proxy

Vue 3 用 Proxy 代理整个对象，拦截各种操作。

6. effect 的执行与清理

  • effect 重新执行前，先把自己从所有 dep 中移除。
  • 执行时重新读取数据，重新收集依赖。
  • 如果不再读取某个数据，就不会再被收集，实现按需更新。

七、Vue 2 与 Vue 3 对比

对比项 Vue 2 Vue 3
核心 API Object.defineProperty Proxy
监听范围 对象已有属性 整个对象，包括增删、数组索引
数组处理 重写数组方法 原生支持
递归方式 初始化时递归 惰性递归，访问时再代理
新增/删除属性 不支持，需Vue.set 支持
Map/Set 不支持 支持
性能 初始化开销大 初始化和内存更优
依赖收集 Dep + Watcher track + effect
异步更新 nextTick 队列 nextTick 队列（类似）

八、常见问题与注意事项

  1. DOM 更新是异步的数据变化后，DOM 不会立即更新，需要 await nextTick() 获取最新 DOM。

  2. reactive 解构丢失响应性

    解决：用 toRefs 或 toRef。

  3. reactive 不能整体替换

    解决：用 ref 或修改属性。

  4. ref.value 解构也会丢失响应性

    解决：toRefs(user.value)、toRef(user.value, 'age') 或 computed。

  5. effect !== activeEffect 防止递归当前 effect 修改自己依赖的数据时，不会被自己触发。

  6. dep 不会在 trigger 后清空
    triggerRefValue 只负责通知，dep 的增删由 track 和 effect 的 cleanup 管理。

九、总结

Vue 2 通过 Object.defineProperty 劫持属性，用 Dep 收集 Watcher，数据变化时通知 Watcher 更新视图。
Vue 3 改用 Proxy 代理整个对象，用 track 收集 effect，用 trigger 触发更新。
两者本质都是“依赖收集 + 派发更新”的发布订阅模式。
响应式系统负责“数据 → 视图”，而“视图 → 数据”靠事件监听（v-model）实现。
