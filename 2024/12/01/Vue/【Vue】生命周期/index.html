Vue 生命周期

Vue 生命周期

一、Vue2 生命周期（表格）

钩子 触发时机 可访问 data / methods 等 DOM 状态 典型用途 / 注意
beforeCreate 实例初始化之后，数据观测和事件配置之前 ❌ 未生成 无法访问data、methods，一般很少用
created 实例创建完成，数据观测、watch/event 配置完成 ✅ 未生成 可发起请求、初始化数据，但不能操作 DOM
beforeMount 挂载开始之前，render 首次调用前 ✅ 未挂载 模板已编译，尚未挂载到 DOM
mounted 挂载完成，$el 已被新创建的 DOM 替换 ✅ 已挂载 DOM 操作、请求、初始化第三方库
beforeUpdate 数据变化，虚拟 DOM 重新渲染 / 打补丁之前 ✅ 旧 DOM 可获取更新前的 DOM 状态
updated 虚拟 DOM 重新渲染 / 打补丁完成 ✅ 新 DOM DOM 已更新；避免修改状态导致无限循环
beforeDestroy 实例销毁之前 ✅ 实例仍可用 清理定时器、解绑事件、取消请求
destroyed 实例销毁之后 ❌ 实例已销毁 所有指令解绑、事件监听移除、子实例销毁
activated keep-alive 组件激活时 ✅ 可用 首次挂载后也会触发；可恢复定时器 / 状态
deactivated keep-alive 组件停用时 ✅ 可用 暂停定时器、保存状态
errorCaptured 捕获后代组件错误时 ✅ — 返回false 可阻止错误继续向上传播
serverPrefetch SSR 中，服务器渲染组件之前 ✅ 未生成 Vue 2.6+，服务端预取数据

生命周期执行顺序

  1. 加载渲染过程父 beforeCreate → 父 created → 父 beforeMount → 子 beforeCreate → 子 created → 子 beforeMount → 子 mounted → 父 mounted
  2. 更新过程父 beforeUpdate → 子 beforeUpdate → 子 updated → 父 updated
  3. 销毁过程父 beforeDestroy → 子 beforeDestroy → 子 destroyed → 父 destroyed
  4. keep-alive 场景
    首次挂载后触发 activated；离开缓存组件时触发 deactivated；再次进入时再次触发 activated。

二、Vue3 生命周期

1. 对照表

阶段 Vue2 Vue3 选项式 API Vue3 组合式 API
创建前 beforeCreate beforeCreate setup
创建后 created created setup
挂载前 beforeMount beforeMount onBeforeMount
挂载后 mounted mounted onMounted
更新前 beforeUpdate beforeUpdate onBeforeUpdate
更新后 updated updated onUpdated
卸载前 beforeDestroy beforeUnmount onBeforeUnmount
卸载后 destroyed unmounted onUnmounted
keep-alive 激活 activated activated onActivated
keep-alive 停用 deactivated deactivated onDeactivated
错误捕获 errorCaptured errorCaptured onErrorCaptured
调试追踪 无 renderTracked onRenderTracked
调试触发 无 renderTriggered onRenderTriggered
SSR 预取 serverPrefetch serverPrefetch onServerPrefetch

注意：Vue3 选项式 API 中 beforeCreate / created 仍然存在；组合式 API 中由 setup 替代，且 setup 在 beforeCreate 之前执行。

2. Vue3 组合式 API 父子组件执行顺序

  • 挂载：父 setup → 父 onBeforeMount → 子 setup → 子 onBeforeMount → 子 onMounted → 父 onMounted
  • 更新：父 onBeforeUpdate → 子 onBeforeUpdate → 子 onUpdated → 父 onUpdated
  • 卸载：父 onBeforeUnmount → 子 onBeforeUnmount → 子 onUnmounted → 父 onUnmounted

如果混合使用选项式 API，setup 仍在 beforeCreate 之前执行。

三、各钩子典型用途与注意事项

1. 创建阶段

  • setup：组合式 API 入口，替代 beforeCreate / created，不能使用 this。
  • beforeCreate / created：选项式 API 中仍可用，created 可访问数据，但 DOM 尚未生成。

2. 挂载阶段

  • onBeforeMount / beforeMount：挂载前，DOM 未生成。
  • onMounted / mounted：挂载完成，可访问 DOM、发起请求、初始化第三方库。

3. 更新阶段

  • onBeforeUpdate / beforeUpdate：数据变化后，DOM 更新前，此时 DOM 仍是旧值。
  • onUpdated / updated：DOM 更新后。不要在此修改状态，可能导致无限循环。

4. 卸载阶段

  • onBeforeUnmount / beforeUnmount：卸载前，实例仍可用，适合清理定时器、取消请求、解绑事件。
  • onUnmounted / unmounted：卸载后，所有指令解绑、事件监听移除。

5. keep-alive

  • onActivated / activated：组件被激活时触发，首次挂载后也会触发。
  • onDeactivated / deactivated：组件被停用时触发，适合暂停定时器、保存状态。

6. 错误与调试

  • onErrorCaptured / errorCaptured：捕获后代组件错误，返回 false 可阻止错误继续传播。
  • onRenderTracked / onRenderTriggered：仅开发环境，用于调试响应式依赖追踪与触发。

7. SSR

  • onServerPrefetch / serverPrefetch：服务端渲染时预取数据。

8. 注册规则

  • 组合式 API 钩子必须在 setup 中同步注册，不能放在异步回调中。
  • 同一钩子可以注册多个，按注册顺序执行。

四、快速记忆

  • Vue2 销毁：beforeDestroy → destroyed
  • Vue3 卸载：beforeUnmount → unmounted
  • Vue3 组合式创建：setup 替代 beforeCreate / created
  • 父子顺序：挂载时子先 mounted，父后 mounted；卸载时子先 unmounted，父后 unmounted
  • keep-alive：onActivated / onDeactivated
  • 清理工作放：onBeforeUnmount / beforeUnmount
  • 调试用：onRenderTracked / onRenderTriggered（仅开发环境）
