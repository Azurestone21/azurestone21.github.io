Vue watch 和 watchEffect

【Vue】watch 和 watchEffect

在 Vue 3 的 Composition API 中，watch 和 watchEffect 都是用来监听响应式数据变化并执行副作用的。核心区别一句话概括：

watch 是“显式指定依赖，惰性执行”；watchEffect 是“自动收集依赖，立即执行”。

一、watch

1. 基本用法

  • 默认惰性：只有 count 变化才执行。
  • 可以拿到新值、旧值。

2. 监听多个源

3. 监听 getter 函数

⚠️ 直接监听 reactive 对象会隐式深度监听；监听其单个属性必须用 getter。

4. 常用选项

  • flush配置
    • pre (默认)：回调函数会在 DOM更新之前执行
    • post：回调函数会在 DOM 更新之后执行，在实际开发中，假设你希望滚动到页面的某个位置再执行回调，可以用这个。
    • sync：回调函数会同步执行，也就是在响应式数据发生变化时立即执行。

5. 清理副作用 onCleanup

  • 在副作用重新执行前、停止监听时调用。
  • 可注册多个清理函数。
  • 建议在 await 之前注册。

6. 特点

  • 显式指定监听源：ref、reactive、getter、数组。
  • 默认惰性，源变化才执行。
  • 可以获取 newValue 和 oldValue。
  • 返回停止函数：const stop = watch(...)，调用 stop() 停止。
  • 支持 immediate、deep、flush、once 等精细控制。

二、watchEffect

1. 基本用法

  • 自动追踪回调中访问过的响应式依赖。
  • 默认立即执行一次。
  • 不能直接获取旧值。

2. 清理副作用

3. 执行时机控制

4. 异步注意

watchEffect 只追踪同步执行期间访问的响应式属性。

5. 特点

  • 自动收集依赖，代码简洁。
  • 默认立即执行一次。
  • 不能直接获取旧值。
  • 返回停止函数。
  • 支持 onCleanup 清理副作用。
  • 直接监听 reactive 对象时会隐式深度监听。
  • 监听 reactive 对象的单个属性时，必须用 getter，例如 () => state.count。

三、核心区别对比

对比项 watch watchEffect
依赖收集 显式指定监听源 自动收集回调中访问的依赖
执行时机 默认惰性，源变化才执行 默认立即执行一次
新旧值 可获取newValue / oldValue 不能直接获取旧值
监听多个源 用数组显式声明 自动追踪多个依赖
适用场景 需要旧值、条件执行、明确依赖、异步竞态处理 简单副作用、依赖多且不想手动列、立即执行
停止监听 返回停止函数 返回停止函数
清理副作用 支持onCleanup 支持onCleanup
精细控制 immediate、deep、once 等 flush、watchPostEffect、watchSyncEffect

四、如何选择

用 watch

  • 需要知道变化前后的值。
  • 只想在某个特定数据变化时执行。
  • 需要 immediate、deep、once 等精细控制。
  • 处理异步请求并防止竞态。

用 watchEffect

  • 副作用依赖多个响应式数据，不想手动列依赖。
  • 逻辑简单，不需要旧值。
  • 希望创建时立即执行一次。
  • 例如：根据多个筛选条件自动请求数据、同步 localStorage、打印日志等。

快速记忆：
要旧值、要精准控制，用 watch；依赖多、想省事、立即执行，用 watchEffect。

五、总结

  • watch：显式依赖、惰性、有新旧值、可精细控制。
  • watchEffect：自动依赖、立即执行、无旧值、代码简洁。
  • 清理副作用：Vue 用 onCleanup(fn)，React 用 return fn。
  • 异步请求防竞态：Vue 在 onCleanup 中取消；React 在 cleanup 中取消。
  • 停止监听：Vue 调用 stop()；React 靠依赖变化或卸载。

六、补充：onCleanup 与 React useEffect 的 return

相似点

维度 VueonCleanup ReactuseEffect return
目的 清理上一次副作用 清理上一次副作用
调用时机 副作用重新执行前、停止监听时 effect 重新执行前、组件卸载时
顺序 先 cleanup，再执行新副作用 先 cleanup，再执行新 effect
闭包 捕获当次执行的值 捕获当次 effect 的值
典型用途 取消异步请求、清除定时器 取消异步请求、清除定时器

关键区别

维度 VueonCleanup ReactuseEffect return
注册方式 通过回调参数onCleanup(fn) 注册，可注册多个 通过return fn 返回，只能返回一个
异步限制 watch / watchEffect 回调可以是 async 函数 useEffect 回调不能是 async 函数
依赖追踪 watchEffect 自动追踪；watch 显式指定 依赖数组显式声明
执行时机 watchEffect 默认 flush: 'pre' 浏览器绘制后异步执行
停止 API 返回stop()，可手动停止 无显式停止 API

总结

Vue 的 onCleanup ≈ React useEffect 的 return 清理函数，都是“副作用清理钩子”。
但 Vue 用回调参数注册，可以注册多个，支持 async 回调；React 用返回值返回，只能返回一个，且回调必须同步。
