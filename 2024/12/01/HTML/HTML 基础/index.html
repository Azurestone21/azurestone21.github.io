HTML 基础

HTML 基础

超文本标记语言（HyperText Markup Language，简称：HTML）是一种用于创建网页的标准标记语言。

HTML , HTML 4.01的上一个版本诞生于 1999 年。

HTML文档的后缀名：.html 或 .htm

标记语言是一套标记标签 (markup tag)

HTML标签

块标签

h1~h6、p、div、ul、ol、li、dl、dt、dd、form、table

特点

  1. 独占一行。
  2. 可以设置高度（默认是父级的100%）、宽度、外边距、内边距。

行内标签

a、span、em、strong、b、i、u、label、br、img、input、textarea

特点

  1. 一行可以显示多个。
  2. 设置宽高无效，宽度是内容的宽度。
  3. 行内元素只能容纳文本或其他行内元素。

行内块标签

img、input、textarea、td

特点

  1. 一行可以显示多个，之间会有空白缝隙。
  2. 默认宽度就是它本身内容的宽度。
  3. 可以设置高度、宽度、外边距、内边距。

自闭合标签

input、meta、link、br、hr、img

样式标签

  • <style>
  • <link>：引用外部css文件

meta

作用：定义 HTML 文档的元数据，可以包含文档的字符集、视口设置、作者、页面描述、关键字等

属性

  • viewport
    • 是网页实现响应式的工具，可以控制视口大小和缩放
    • 可以适配不同屏幕尺寸，例如设置 width=device-width，initial-scale=1

iframe

内嵌框架。可以在同一个浏览器窗口中显示多个页面。

HTML5

HTML5 是 HTML 的最新版本，由万维网联盟（W3C）在 2014 年完成制订。目的是在移动设备上支持多媒体。

HTML5 仍处于完善之中。

新特性

  1. 语义化元素：article、footer、header、nav、section
  2. 多媒体元素：video、audio
  3. 绘画元素：canvas
  4. 表单控件：calendar、date、time、email、url、search
  5. 完全支持 CSS3
  6. 对本地离线存储的更好的支持

语义化标签相对于 div 的优点

  1. 增强可读性
  2. 便于搜索引擎（SEO）

<!DOCTYPE html>

<!DOCTYPE html> 不是一个 html 标签，是一个标记语言的文档类型声明，告诉浏览器当面的 HTML 是什么版本编写的，声明必须位于 HTML5 文档中的第一行。

<!DOCTYPE html> 是 HTML5 的声明，HTML5 之前的版本需要引用 DTD（文档类型定义）

Canvas

canvas 标签用来定义图形容器，但必须使用脚本来绘制图形。

canvas 是一个二维网格。

  1. 使用 <canvas>，需要设置 id、width 和 height。id 用于脚本引用，width 和 height 属性定义的画布的大小。
  2. JS 通过 id 获取canvas元素
  3. getContext 创建 context 对象
  4. 使用 context 对象的方法进行绘画（moveTo、lineTo、fillText）

SVG

HTML5 支持内联 SVG。

Geolocation

用于定位用户的位置。

Web 存储

  • localStorage - 用于长久保存整个网站的数据，保存的数据没有过期时间，直到手动去除。

  • sessionStorage - 用于临时保存同一窗口(或标签页)的数据，在关闭窗口或标签页之后将会删除这些数据。

  • localStorage 和 sessionStorage可使用的API都相同。

  • 保存数据：localStorage.setItem(key,value)

  • 读取数据：localStorage.getItem(key)

  • 删除单个数据：localStorage.removeItem(key)

  • 删除所有数据：localStorage.clear()

  • 得到某个索引的key：localStorage.key(index)

WebSocket

现状：为了实现推送技术，所用的技术都是 Ajax 轮询。轮询是在特定的的时间间隔（如每1秒），由浏览器对服务器发出HTTP请求，然后由服务器返回最新的数据给客户端的浏览器。

WebSocket 是 HTML5 开始提供的一种在单个 TCP 连接上进行全双工通讯的协议。

在 WebSocket API 中，浏览器和服务器只需要完成一次握手，两者之间就直接可以创建持久性的连接，并进行双向数据传输，允许服务端主动向客户端推送数据。

优点：节省服务器资源和带宽，并且能够更实时地进行通讯。

WebSocket 协议本质上是一个基于 TCP 的协议。

建立一个 WebSocket 连接，客户端浏览器首先要向服务器发起一个 HTTP 请求，这个请求和通常的 HTTP 请求不同，包含了一些附加头信息，其中附加头信息”Upgrade: WebSocket”表明这是一个申请协议升级的 HTTP 请求，服务器端解析这些附加的头信息然后产生应答信息返回给客户端，客户端和服务器端的 WebSocket 连接就建立起来了，双方就可以通过这个连接通道自由的传递信息，并且这个连接会持续存在直到客户端或者服务器端的某一方主动的关闭连接。

XHTML

XHTML 指的是可扩展超文本标记语言，以 XML 应用的方式定义的 HTML。

XHTML 是2001年1月发布的 W3C 推荐标准，所有主流浏览器都支持

XHTML 与 HTML 4.01 几乎是相同的，比HTML更严格更纯净。

XHTML 和 HTML 的区别

文档结构

  • XHTML DOCTYPE 是强制性的
  • <html> 中的 XML namespace 属性是强制性的
  • <html>、<head>、title> 以及 <body> 也是强制性的

元素语法

  • XHTML 元素必须正确嵌套
  • XHTML 元素必须始终关闭
  • XHTML 元素必须小写
  • XHTML 文档必须有一个根元素

属性语法

  • XHTML 属性必须使用小写
  • XHTML 属性值必须用引号包围
  • XHTML 属性最小化也是禁止的
