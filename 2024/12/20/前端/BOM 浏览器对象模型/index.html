BOM 浏览器对象模型

BOM 浏览器对象模型

BOM（Browser Object Model，浏览器对象模型）提供了一组用于与浏览器窗口及其能力交互的对象。它关注的不是文档内容本身，而是窗口、地址栏、浏览器信息、屏幕、历史记录、定时器、弹窗等浏览器层面的能力。例如：页面前进后退、刷新、监听窗口尺寸变化和滚动、获取浏览器与屏幕信息等。

可以粗略理解为：页面内容属于 DOM，浏览器窗口及浏览器能力属于 BOM。

需要注意的是，BOM 并不像 DOM 那样有一个独立、统一的标准，相关接口主要定义在 HTML Living Standard 等规范中。早期 BOM 缺乏标准，兼容性差异较大；现代开发应优先使用特性检测，而不是依赖 userAgent 做浏览器嗅探。

1. window：BOM 的核心对象

window 表示浏览器窗口的一个实例，是 BOM 的核心对象。它有两个角色：

  1. 浏览器窗口的接口：用于操作窗口尺寸、位置、滚动、弹窗等。
  2. 全局对象：在浏览器全局作用域中，通过 var 声明的变量和函数声明会成为 window 的属性和方法；但 let、const、class 等声明不会自动成为 window 的属性。

document、location、navigator、screen、history 等对象都可以通过 window 访问，通常可以省略 window. 前缀。

2. 窗口位置、尺寸与滚动

属性 说明
window.screenX 浏览器窗口左上角相对于屏幕左上角的水平距离，只读。
window.screenY 浏览器窗口左上角相对于屏幕左上角的垂直距离，只读。
window.innerWidth 浏览器视口（viewport）宽度，包含滚动条，只读。
window.innerHeight 浏览器视口（viewport）高度，包含滚动条，只读。
window.outerWidth 整个浏览器窗口的宽度，只读。
window.outerHeight 整个浏览器窗口的高度，只读。
window.scrollX 文档水平方向已滚动的像素值，只读。
window.scrollY 文档垂直方向已滚动的像素值，只读。
window.pageXOffset window.scrollX 的别名。
window.pageYOffset window.scrollY 的别名。

放大网页时，window.innerWidth 和 window.innerHeight 可能变小：网页的 CSS 像素大小不变，但每个像素占用的屏幕空间变大，因此视口内可见的内容变少。

3. location：地址栏与 URL 信息

location 对象提供当前文档 URL 的信息，并可用于页面跳转。

属性名 例子 说明
hash "#contents" URL 中 # 后面的字符，没有则返回空串。
host www.wrox.com:80 服务器名称和端口号。
hostname www.wrox.com 域名，不带端口号。
href http://www.wrox.com:80/WileyCDA/?q=javascript#contents 完整 URL。
pathname "/WileyCDA/" 服务器下面的文件路径。
port "80" URL 的端口号，没有则为空。
protocol "http:" 使用的协议，带冒号。
search "?q=javascript" URL 的查询字符串，通常为 ? 后面的内容。

常用方法：

  • location.assign(url)：加载新文档，并生成一条历史记录。
  • location.replace(url)：加载新文档，并替换当前历史记录。
  • location.reload()：刷新当前页面。根据缓存策略，可能从浏览器缓存中重新加载。
  • 修改 location.href 等价于调用 assign()。

4. navigator：浏览器与运行环境信息

navigator 对象表示用户代理（浏览器）的状态，提供浏览器和运行环境信息。常用属性包括：

  • navigator.userAgent：浏览器的 User-Agent 字符串，包含浏览器类型、版本、操作系统等信息。但该字符串可被修改，不推荐用于精确判断浏览器类型。
  • navigator.platform：浏览器运行的平台信息，如 Windows、macOS、Linux 等。该信息已趋于过时，不建议用于精确判断设备或系统。
  • navigator.language：浏览器当前的首选语言，如 zh-CN、en-US。
  • navigator.languages：用户偏好的语言列表，按优先级排序。
  • navigator.cookieEnabled：表示浏览器是否启用了 Cookie。
  • navigator.onLine：表示浏览器是否处于联网状态。
  • navigator.hardwareConcurrency：可用的逻辑处理器内核数。

5. screen：屏幕信息

screen 对象提供客户端显示器的信息，是只读对象。常用属性包括：

属性 说明
screen.width 屏幕总宽度，单位为像素。
screen.height 屏幕总高度，单位为像素。
screen.availWidth 屏幕可用工作区宽度，单位为像素。
screen.availHeight 屏幕可用工作区高度，单位为像素。
screen.colorDepth 屏幕颜色深度，单位为位。
screen.pixelDepth 屏幕像素深度，单位为位，通常与 colorDepth 相同。

width / height 表示屏幕总分辨率；availWidth / availHeight 表示减去操作系统任务栏、Dock 等界面元素后，浏览器窗口可用的工作区尺寸。

6. history：历史记录

history 对象用于操作浏览器的历史记录：

  • history.go(delta)：向前或向后跳转指定步数。
  • history.forward()：向前跳转一个页面。
  • history.back()：向后跳转一个页面。
  • history.length：获取历史记录数量。

现代浏览器还支持 history.pushState() 和 history.replaceState()，用于在不刷新页面的情况下操作历史记录。

7. 定时器

  • setTimeout(fn, delay)：指定延迟后执行一次，返回定时器 ID。
  • setInterval(fn, delay)：每隔指定时间执行一次，返回定时器 ID。

8. 弹窗

  • alert(message)：显示警告框，用户必须点击确定。
  • confirm(message)：显示确认框，返回 true 或 false。
  • prompt(message, default)：显示输入框，返回用户输入的字符串；取消时返回 null。

弹窗会阻塞页面交互，实际项目中不宜滥用。

9. 滚动与窗口缩放

滚动相关方法：

  • window.scrollTo(x, y)：滚动到指定位置。
  • window.scrollTo(options)：使用配置对象滚动，例如 { left, top, behavior: 'smooth' }。
  • window.scroll(x, y)：行为与 scrollTo() 相同。
  • window.scrollBy(x, y)：相对当前位置滚动指定像素。
  • window.scrollBy(options)：使用配置对象进行相对滚动。

窗口缩放相关方法：

  • window.resizeTo(width, height)：将窗口调整到指定大小。
  • window.resizeBy(dx, dy)：相对当前窗口大小调整指定像素。

注意：现代浏览器通常只允许对脚本打开的窗口调整大小，普通标签页可能受到限制。

10. requestAnimationFrame

window.requestAnimationFrame(callback) 告诉浏览器希望在下次重绘之前执行一个回调函数，并返回一个请求 ID。回调函数会接收一个高精度时间戳参数。

12. BOM 与 DOM 的区别

DOM（Document Object Model，文档对象模型）负责文档的结构和内容，入口是 document；BOM 负责浏览器窗口和浏览器能力，核心是 window。

DOM 有明确的标准；BOM 相关接口分散在 HTML 标准等规范中，历史兼容性更复杂。在浏览器中，document 是 window 的属性，因此可以通过 window.document 访问 DOM，但 DOM 并不是 BOM 的组成部分，二者是并列的 Web API。

实践中，BOM 常用于：页面跳转、读取 URL 参数、前进后退、监听窗口大小和滚动、弹窗、定时器、获取浏览器与屏幕信息等。进行浏览器能力判断时，应优先使用特性检测，而不是依赖 userAgent。
