执行上下文

JavaScript 中的执行上下文（Execution Context），可以理解为“代码执行时所处的环境”。它决定了变量、函数、this、作用域链等如何被访问。每当 JS 引擎要执行一段代码时，都会先创建一个执行上下文。

JS 中主要有三种执行上下文：

  1. 全局执行上下文：整个程序只有一个，页面/脚本开始执行时创建。
  2. 函数执行上下文：每次调用函数都会创建一个新的，函数调用结束后通常销毁。
  3. eval 执行上下文：eval() 中的代码会创建，不推荐使用。

此外，ES Module 也有自己的模块执行上下文。

二、执行上下文的生命周期

一个执行上下文通常经历三个阶段：

  1. 创建阶段
  2. 执行阶段
  3. 销毁阶段

1. 创建阶段

创建阶段主要做三件事：

  1. 确定 this
  2. 创建词法环境
  3. 创建变量环境

在 ES5/ES6 之后，执行上下文内部大致包含：

  • LexicalEnvironment：词法环境
  • VariableEnvironment：变量环境
  • ThisBinding：this 绑定
  • 可能还有 PrivateEnvironment、Function、Realm 等规范内部字段

在更老的 ES3 说法中，叫：

  • 变量对象 VO
  • 活动对象 AO
  • 作用域链
  • this

现在通常用“词法环境 / 变量环境”来解释。

三、词法环境和变量环境

1. 词法环境 LexicalEnvironment

词法环境用于处理块级作用域相关的声明，比如：

  • let
  • const
  • class
  • 块级函数声明

它包含两部分：

  • EnvironmentRecord：保存当前环境中的变量、函数等绑定。
  • OuterEnv：指向外层词法环境，形成作用域链。

环境记录常见类型：

  • 声明式环境记录：函数、块、模块、catch
  • 对象式环境记录：with、全局对象记录
  • 全局环境记录：全局对象记录 + 声明记录
  • 函数环境记录：包含 this、arguments、new.target 等

2. 变量环境 VariableEnvironment

变量环境主要用于处理：

  • var 声明
  • 函数声明

在全局或函数代码创建时，LexicalEnvironment 和 VariableEnvironment 通常最初指向同一个环境。但进入块级作用域时，会创建新的词法环境，而变量环境不变。

所以：

  • var 是函数级作用域，绑定在变量环境。
  • let / const 是块级作用域，绑定在当前词法环境。

四、创建阶段具体做了什么？

以函数执行上下文为例，调用函数时，创建阶段会：

  1. 创建函数环境记录。
  2. 绑定形参。
  3. 创建 arguments 对象，箭头函数没有自己的 arguments。
  4. 处理函数声明，函数声明整体提升。
  5. 处理 var 声明，初始化为 undefined。
  6. 处理 let / const，创建绑定但未初始化，形成暂时性死区 TDZ。
  7. 确定 this。
  8. 建立外部环境引用，形成作用域链。

然后进入执行阶段，逐行执行代码，进行赋值、函数调用等。

六、this 绑定

this 是执行上下文的一部分，但它的值取决于调用方式。

常见规则：

  1. 默认绑定
    • 非严格模式：普通函数调用，this 指向全局对象。
    • 严格模式：this 是 undefined。
  1. 隐式绑定
    • 通过对象调用，this 指向该对象。
  1. 显式绑定
    • call、apply、bind 指定 this。

  1. new 绑定

    • new 调用构造函数，this 指向新创建的对象。

  2. 箭头函数

    • 箭头函数没有自己的 this，它继承定义时外层作用域的 this。

全局代码中，this 通常指向全局对象；ES Module 顶层 this 是 undefined。

七、作用域链

每个词法环境都有 OuterEnv，指向外层词法环境。变量查找时，会从当前环境开始，逐层向外查找，直到全局环境。

八、闭包与执行上下文

函数执行完后，它的执行上下文会出栈，但它的词法环境不一定销毁。如果内部函数引用了外层变量，并且内部函数被返回或保存，那么外层词法环境会被保留，形成闭包。

十、总结

概念 说明
执行上下文 代码执行时的环境
全局执行上下文 只有一个，程序开始时创建
函数执行上下文 每次函数调用创建
eval 执行上下文 eval 代码创建，不推荐
执行上下文栈 管理执行上下文，栈顶是当前上下文
词法环境 处理 let、const、class、块级作用域
变量环境 处理 var、函数声明
环境记录 保存变量和函数绑定
OuterEnv 指向外层环境，形成作用域链
this 由调用方式决定，箭头函数继承外层
变量提升 var 初始化为 undefined，函数声明整体提升
TDZ let/const 声明前访问报错
闭包 函数保留外层词法环境

一句话概括：

执行上下文是 JS 代码运行时的环境，它通过词法环境、变量环境、this 绑定和作用域链，决定了变量如何查找、函数如何提升、this 指向哪里，以及闭包如何形成。
