Vue 入门

Vue 是一个用于构建用户界面的渐进式 JavaScript 框架，由尤雨溪（Evan You）创建并开源。它发音类似“view”，核心关注视图层，但配合官方生态可以构建完整的单页应用（SPA）、服务端渲染应用和静态站点。

核心特点

  1. 声明式渲染只需描述数据与视图的关系，Vue 自动更新 DOM。例如：

  2. 响应式系统数据变化自动触发视图更新。Vue 3 使用 Proxy 实现，Vue 2 使用 Object.defineProperty。

  3. 组件化开发将页面拆分为可复用的组件。Vue 推荐使用单文件组件（SFC），即 .vue 文件：

  4. 渐进式可以只引入一个脚本增强现有页面，也可以搭配路由、状态管理、构建工具开发大型应用。

  5. 虚拟 DOM 与编译优化
    Vue 3 在编译时做静态提升、补丁标记等优化，运行时性能更好，体积更小。

主要版本

  • Vue 3：当前主流版本，2020 年发布。支持 Composition API、更好的 TypeScript 支持、Fragment 多根节点、Teleport、Suspense、Tree-shaking 等。
  • Vue 2：已于 2023 年 12 月 31 日停止维护，新项目建议直接使用 Vue 3。

核心概念

  • 模板语法：插值 {{ }}、指令 v-bind、v-on、v-if、v-for、v-model。
  • Options API：通过 data、methods、computed、watch、生命周期钩子组织代码。
  • Composition API：通过 setup、ref、reactive、computed、watch、onMounted 等函数组织逻辑，更适合复杂组件和逻辑复用。
  • 组件通信：props、emit、provide/inject、v-model、插槽等。
  • 生命周期：如 onMounted、onUpdated、onUnmounted。

生态系统

  • 构建工具：Vite（官方推荐）、Vue CLI（旧）
  • 路由：Vue Router
  • 状态管理：Pinia（官方推荐）、Vuex（旧）
  • 服务端渲染/全栈：Nuxt
  • 静态站点：VitePress、VuePress
  • UI 组件库：Element Plus、Ant Design Vue、Vuetify、Naive UI 等
  • 调试工具：Vue Devtools

优点

  • 上手容易，中文文档质量高。
  • 响应式系统直观，开发效率高。
  • 组件化清晰，代码可维护性好。
  • 性能优秀，工具链完善。
  • 社区活跃，生态成熟。

适用场景

  • 单页应用（SPA）
  • 后台管理系统
  • 移动端 H5、混合应用
  • 快速原型开发
  • 在现有页面中局部增强交互

总的来说，Vue 是一个易学、灵活、性能好的前端框架，适合从简单页面到大型应用的各类项目。如果你是初学者，建议从 Vue 3 + Vite + Composition API 开始学习。
