前端常见攻击

前端常见攻击

1. XSS 跨站脚本

前端最常考，分三类：

  • 反射型：URL 参数直接输出到页面。
  • 存储型：恶意内容存进数据库，所有访问者中招，危害最大。
  • DOM 型：前端 JS 从 location、innerHTML 等取数据写入 DOM。

危害：窃取 Cookie、Token、冒充用户、钓鱼、蠕虫。
防御：输出编码、输入校验、避免 innerHTML/eval，用 textContent，CSP，Cookie 加 HttpOnly。

2. CSRF 跨站请求伪造

利用浏览器自动携带 Cookie，诱导用户点击后以用户身份发请求。
和 XSS 区别：XSS 是“执行恶意脚本”，CSRF 是“借用户身份发请求”。
防御：CSRF Token、SameSite=Lax/Strict、校验 Origin/Referer、关键操作二次验证。

3. 点击劫持

用透明 iframe 盖在正常按钮上，诱导点击。
防御：X-Frame-Options: DENY/SAMEORIGIN、CSP: frame-ancestors。

4. 同源策略与 CORS 配置错误

同源策略是浏览器防线：协议 + 域名 + 端口。
CORS 本身不是攻击，但配置错误会出事：

  • Access-Control-Allow-Origin: * 还带 credentials
  • 反射任意 Origin
  • 信任子域但子域可被 XSS

防御：白名单 Origin，不要随便 *，严格校验。

5. postMessage 滥用

window.postMessage 跨窗口通信。
常见漏洞：

  • 发送时 targetOrigin 用 *
  • 接收时不校验 event.origin
  • 直接把 event.data 插入 DOM

防御：发送指定具体源，接收校验 origin/source，数据当不可信处理。

6. 原型污染

通过 __proto__、constructor.prototype 污染 Object.prototype，影响全局对象，可能升级为 XSS。
防御：过滤 __proto__/constructor/prototype，Object.create(null)，冻结原型，用 Map。

7. DOM Clobbering

用 HTML 的 id/name 覆盖全局变量，比如 <img name="config"> 让 window.config 变成元素，绕过脚本逻辑。
防御：不依赖全局变量，用 let/const，严格模式，CSP。

8. 供应链攻击

npm 恶意包、CDN 被篡改、依赖投毒。
防御：package-lock、npm audit、SRI、私有 registry、最小依赖。

9. 敏感信息泄露

前端常见：

  • Token 存 localStorage，被 XSS 一读就没了
  • 源码 map 泄露
  • 前端硬编码 API Key
  • 错误信息暴露内部结构

建议：敏感凭证放后端，Token 优先 HttpOnly + Secure + SameSite Cookie，短期 Token 可放内存。

10. 其他前端相关

  • 开放重定向：?next=//evil.com，用于钓鱼。
  • Tabnabbing：target="_blank" 不加 rel="noopener"，新页面可操作 window.opener。
  • JSONP 劫持：敏感数据用 JSONP 暴露，任何站都能读。
  • XS-Leaks：侧信道推断跨站信息。
  • MITM / 混合内容：HTTPS 页面加载 HTTP 资源，可被篡改。
  • 安全头缺失：CSP、HSTS、X-Content-Type-Options、Referrer-Policy 等。
