面向对象编程

面向对象编程（Object Oriented Programming，缩写为 OOP）是目前主流的编程范式。

“类”就是对象的模板，对象就是“类”的实例。

JavaScript 语言的对象体系，不是基于“类”的，而是基于构造函数（constructor）和原型链（prototype）。

构造函数

构造函数，就是专门用来生成实例对象的函数。

构造函数名字的第一个字母通常大写。

特点

  1. 函数体内部使用了this关键字，代表了所要生成的对象实例。
  2. 生成对象的时候，必须使用new命令。

静态方法

直接定义给构造函数的方法。静态方法使用 类名.方法名 去调用。

构造函数所创建的实例不可以调用静态方法。

实例方法

在构造函数上用this指向新创建的实例，用 this.方法名 = function ( ) {…} 的方式给每个新创建的实例添加方法，这种方式添加的方法称为实例方法。

每个实例在创建时都会定义实例方法，每个实例的实例方法都是独有的，不与其它实例共有。

实例方法通过 实例.方法名 去调用。构造函数不可调用实例方法。

原型方法

定义在构造函数的原型对象上的方法，是所有实例公共的方法。

构造函数不可以调用原型方法。实例调用构造函数原型对象上的方法的方式：构造函数名.prototype.方法名 。

在构造函数（constructor）内部和外部定义方法有什么区别

  • 内部：
    • 实际上是在每个对象实例上创建了一个新的函数。是各个实例对象独有的。（实例方法）
    • 可以被object.keys() 遍历。
  • 外部
    • 实际上是在Person的原型对象（Person.prototype）上创建的。所有Person实例共享的。（原型方法）
    • 不能被Object.keys() 遍历。

new

new，执行构造函数，返回一个实例对象。

new命令本身就可以执行构造函数，所以后面的构造函数可以带括号，也可以不带括号。

避免不使用new命令、直接调用构造函数。
可以在构造函数内部使用严格模式，在第一行加上use strict，这样一旦没有使用new，会报错。

new原理

  1. 创建一个空对象，作为将要返回的对象实例。
  2. 将这个空对象的原型，指向构造函数的prototype属性。
  3. 将这个空对象赋值给函数内部的this关键字。
  4. 开始执行构造函数内部的代码。

构造函数内部，this指的是一个新生成的空对象。

如果构造函数内部有return语句，而且return后面跟着一个对象，new命令会返回return语句指定的对象；否则，就会不管return语句，返回this对象。

new.target

如果当前函数是new命令调用，new.target指向当前函数，否则为undefined。

可以判断是否时构造函数。
